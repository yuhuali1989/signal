# 第 12 章 · 反方、决策树与落地手册（全书结论）

## 12.1 智能爆炸为什么还没发生：五大制约

把首篇论文的四大制约与本书的论证合起来，是五个而不是四个：

| # | 制约 | 谁提出 | 为什么算力堆不掉 |
|---|---|---|---|
| 1 | **算力** | 首篇 RSI 论文 | 循环放大实验与训练成本，边际收益递减 |
| 2 | **数据** | 同上 | 高质量研发数据有限；合成数据回灌导致模型/多样性崩塌（第 6 章） |
| 3 | **实验时间** | 同上 | 想法生成再快，物理评测仍需墙钟 |
| 4 | **科研收益递减** | 同上 | 容易摘的果子先被摘完 |
| 5 | **验证瓶颈 + 方向设定** | 本书第 6、7 章 | 「算不算进步」的信号强度不随算力增长；「什么值得研究」连量纲都没有 |

第 5 条是本书加的，也是最硬的一条。前四条至少可以用「更多算力 / 更多数据 / 更久时间」部分缓解，**第五条不能**：验证器被优化后，算力越多错得越快；方向设定问题甚至无法写进目标函数。

所以一个准确的判断：**RSI 的强主张不是「被证伪」，而是「连可测量的量都还没定义好」**。L2 公开达标数 0，不是因为有系统试了没成，而是绝大多数宣称根本没做跨轮点火检验。

## 12.2 三个口径陷阱（收口版）

第 5 章展开过，这里压成三行，方便引用：

1. **代码行数 / 生成占比**：数量非质量，官方自己写「几乎肯定高估真实生产力增益」；
2. **97% vs 23%**：问题人定、评分人定、未能干净迁移到生产级模型；同系统开放式研究 6 天 $3,000 被双双拒稿；
3. **8× / 1.5 年 ×10**：情景估算，原文明说证据不足以证明智能爆炸已发生。

再加一条元规则：**看到「自我改进」四个字，先问改的是 learner 还是 improver**（第 1 章判据一、第 7 章 L1/L2 分水岭）。

## 12.3 决策树：什么时候做，什么时候别做

```python
def should_do_rsi(task):
    if not has_cheap_reliable_oracle(task):        # 第 6 章 V0/V1
        return "NO — 先去建验证器，别建自改循环"
    if not can_freeze_evaluator(task):            # 评估器能否划出 scope
        return "NO — 评估器会被自己改掉"
    if not can_rollback_within_minutes(task):     # 30 天母亲版本 / 自动回滚
        return "NO — 先补回滚链路"
    if artifact_not_readable(task):               # 权重不可 diff vs 脚手架可 diff
        return "PREFER_SCAFFOLD — 改规则书/技能代码，别改权重"
    if goal_is_ignition(task):                    # 想要 L2
        return "RESEARCH_ONLY — 别当上线条件，接受大概率不显著"
    return "YES — 做 L1，收益实打实，风险可控"
```

翻译成分场景表：

| 场景 | 建议 | 理由 |
|---|---|---|
| 算子/内核优化、代码重构、SWE 任务 | **做** | 有 V0 等价性与单测 |
| 数学题、可校验推理 | **做** | 有符号校验 oracle |
| 数据配比、训练策略 | 谨慎 | oracle 弱，易过拟合可变集 |
| 开放式写作、对话质量 | 别做自动准入 | 只有 V3 judge，只能当参考 |
| 研究选题、评估器自身 | **别做** | 无可改且独立的真值（第 3 章空白区） |
| 想宣称「点火」 | 只做研究 | 需要第 7 章跨轮对照，且举证责任在你 |

## 12.4 八步落地手册

顺序不能换——前四步带来的收益比第五步以后全部加起来还大：

1. **建冻结集**：内容 + hash + 金丝雀（历史失败样本），CI 里禁止自改产物触碰 `eval/**`；
2. **定报告 schema**：第 8.2 节那份 YAML，先有字段再谈流程；
3. **接确定性验收与自动回滚**：V0/V1 优先，回归超阈值自动 reject（K3.5 形态）；
4. **保留 30 天母亲版本 + 演练恢复**：没演练过的回滚等于没有；
5. **补三条反事实臂与预算对齐**（含人工审核预算）；
6. **补 replay / 留出环境 / 多种子 / 置信区间**；
7. **披露可变集与公开榜单重合度**，让刷分可见；
8. **最后才做跨轮点火检验**，并接受 `demonstration` 或 L1 作为诚实结论。

指标看板别只放分数：

```yaml
metrics:
  engineering:                 # 上线看这些
    - acceptance_rate          # 采纳率（含拒绝率，必须一起报）
    - rollback_count           # 自动拦截次数，为 0 要警惕
    - frozen_regression_delta  # 冻结集回归
    - canary_failure_rate
    - gpu_hours_per_accepted   # 分母含审核与搜索
  research:                    # 研究看这些，别混进上线 KPI
    - ignition_delta           # 匹配资源下的 improver 增益
    - state_inherited_gap      # 去掉保留状态掉多少
    - holdout_transfer_gap
```

`rollback_count = 0` 要当成告警而不是喜报：一个从不拦截的评估器，大概率只是没接进准入路径（第 9 章采购十问第 10 条）。

## 12.5 组织分工

```
人    ：定目标、定冻结集、定 scope 与阈值、仲裁灰区、持有算力回收权
流水线：提候选、跑 V0/V1、冻结集回归、accept/reject、自动回滚、写 hash 链
第三方：验报告、查重合度、抽查恢复演练
```

第 6 章那句在这里落成组织结论：**人在环不是能力补丁，是方向设定与最终兜底的制度位置。** 把「人」从流程里拿掉，等于把第 3 章 ④ × C3 那个做不到的格子当成了前提。

## 12.6 最值得投入的三件事

按 2026 年的证据排序，投入产出比从高到低：

1. **治理级测量**（第 7 章）：把「改进速率」变成可审计、可跨供应商比较的指标——全领域最空白、最有定义权；
2. **脚手架而非权重**（第 3、5 章）：规则书、技能代码、算子 diff、harness 可读可 diff 可回滚，Memento 3 / Auriga / K3.5 都在这条线上；
3. **验证器工程**（第 6 章）：确定性验收、隔离执行、金丝雀、冻结集——它决定你能安全吃下多少自改收益。

**最不值得投入的是更强的自改算法**。候选从来不缺（第 6.1 节），AIDE² 90% 提案被拒就是证据。

## 12.8 全书十条结论

1. **RSI 在 2026 年落地的是有界自精化（L1），不是智能爆炸**；L2 公开达标数为 0。
2. 分水岭是**改 learner 还是改 improver**；改权重不等于二层循环。
3. 干净的理论对象（Gödel Machine）跑不动，跑得动的对象（DGM）都不干净；**可证明 → 可验证 → 可审计**是三次降级，也是三次工程化。
4. **改什么 × 闭环程度**这张坐标里，③评估器 × C2 是原理性空白，④研究流程 × C2 是能力性空白。
5. **瓶颈是验证，不是生成**；自我改进强度与验证信号强度单调同序。
6. **self-improvement 与 self-poisoning 是同一个循环，只差一个 oracle**；四类失败共用根因「弱信号替代强信号」。
7. 假成功写进记忆/技能库/数据管线会被跨轮放大，所以 LLM Judge **只记录、不准入**。
8. 点火有可写进脚本的判据：共同起点、匹配资源、独立留出、多种子显著，且 `state_inherited` 消融成立。
9. 学术可复现与产业可采购是同一套字段；**举证责任在宣称方，默认结论是 L1 或 demonstration**。
10. 2026 年 RSI 的实质进展在**证据链**（产品化流水线、公开拦截案例、统一报告格式），不在智能曲线；最值得投入的是治理级测量，不是更强的自改算法。

## 12.9 一句话收尾

> **别问模型能不能改进自己，先问：这次改动，谁在用什么量、以什么身份判定它变好了——那个量能不能被这次改动碰到。**

答不上来，就是自我投毒；答得上来且留得下 hash 链，才配叫递归自我改进。
