# 第 1 章：VLA 与世界模型——定义、演进与统一愿景

## 1.1 两个范式的定义

### 1.1.1 VLA（Vision-Language-Action）

VLA 是一个端到端的 Transformer 模型，接收视觉观测（摄像头图像）和自然语言指令作为输入，直接输出机器人控制动作：

```
输入: (图像帧 I_t, 语言指令 ℓ, 本体状态 q_t)
输出: 动作 a_t = [Δx, Δy, Δz, Δrx, Δry, Δrz, gripper]
```

VLA 的核心洞察是：**互联网规模的视觉-语言预训练提供了丰富的世界知识，可以直接迁移到物理机器人控制**。一个在数十亿图文对上预训练的 VLM，已经理解了"红色杯子""厨房台面""拿起"这些概念——机器人学习阶段只需将这些概念锚定到物理动作空间。

架构上，VLA 通常包含三个组件：

| 组件 | 功能 | 典型实现 |
|------|------|----------|
| 视觉编码器 | 将摄像头图像编码为视觉 token | SigLIP、DINOv2、CLIP |
| 语言模型骨干 | 处理视觉 token 和语言指令 token | PaLM、LLaMA、PaliGemma |
| 动作头 | 将 LM 隐状态映射为连续/离散动作 | 自回归 token、Diffusion、Flow Matching |

### 1.1.2 世界模型（World Model）

世界模型是一个学习"世界如何运作"的模型——它接收当前观测和（可选的）动作，预测未来状态。与 VLA 不同，世界模型的输出不是"做什么动作"，而是"如果我做了某个动作，世界会变成什么样"。

```
输入: (当前观测 o_t, 动作 a_t)  或  (观测序列 o_{t-k:t})
输出: 未来观测 ŝ_{t+1}（潜在表示或像素）
```

世界模型的三层能力：

| 能力 | 含义 | 评估方式 |
|------|------|----------|
| 理解（Understanding） | 识别视频中的物体、动作、运动 | SSv2、Kinetics 等冻结评估 |
| 预测（Prediction） | 预测世界如何演化、动作如何改变世界 | 动作预测准确率、IntPhys |
| 规划（Planning） | 规划动作序列以达成目标 | 零样本机器人任务成功率 |

### 1.1.3 VLA vs 世界模型：互补而非替代

| 维度 | VLA | 世界模型 |
|------|-----|----------|
| 核心问题 | "现在该做什么？" | "如果我做了X，会怎样？" |
| 输出 | 动作 a_t | 未来状态 ŝ_{t+1} |
| 训练信号 | 模仿学习（专家演示） | 自监督/视频预测 |
| 数据需求 | 标注的（图像,指令,动作）三元组 | 无标注视频即可 |
| 推理模式 | 前馈（观测→动作） | 迭代（预测多步未来） |
| 核心优势 | 快速反应、指令跟随 | 可模拟、可规划、可生成数据 |

二者的关系类似于人类的"系统1"（快速直觉反应）和"系统2"（想象与规划）。VLA 是反射弧，世界模型是想象力——完整的 Physical AI 需要两者协作。

## 1.2 从模块化到端到端：机器人栈的演进

### 1.2.1 传统机器人栈的三重困境

传统机器人系统由三个独立模块串联：感知（CV 模型输出检测框）→ 规划（路径规划器）→ 控制（PID/MPC）。这种架构有三个结构性缺陷：

| 问题 | 根因 | 定量影响 |
|------|------|----------|
| 信息瓶颈 | 感知输出"检测框(4个float)"，丢弃像素级纹理/姿态 | 遮挡场景成功率下降 40%+ |
| 误差累积 | 感知误差→规划偏移→控制超调，无跨模块梯度 | 定位误差每经过一个模块放大约 2.3× |
| 分布偏移脆弱 | 模块间接口是手工定义的语义抽象，换场景即失效 | 新环境需 50-200 条新数据重调 |

### 1.2.2 VLA 的结构性回答

VLA 用一个 Transformer 替代三个模块。损失函数直通输入层：

```
L_VLA = E_{(o_t, a_t) ~ D} [ -Σ_{k=1}^{K} log p_θ(a_t^{(k)} | o_t, a_{t'<t}, ℓ) ]
```

关键在于：视觉 token 和动作 token 共享同一个 Transformer decoder 的 LM head。这意味着：
- Transformer 在处理视觉 token 时，注意力权重已经受"即将预测动作"的隐式偏置调制
- 图文 token 和动作 token 的 embedding 在同一个高维空间（768/4096 维），梯度可以跨模态流动

### 1.2.3 世界模型的历史脉络

世界模型的思想可以追溯到 LeCun 2022 年提出的 JEPA（Joint Embedding Predictive Architecture）构想：**AI 应该在抽象的潜在表示空间中预测，而非重建每个像素**。

| 时间 | 里程碑 | 核心贡献 |
|------|--------|----------|
| 2022 | LeCun JEPA 白皮书 | 提出潜在空间预测的理论框架 |
| 2023 | I-JEPA | 图像级 JEPA 首次验证：无需像素重建即可学好特征 |
| 2024.02 | V-JEPA | 扩展到视频：冻结评估 SOTA，但无法动作 |
| 2024.12 | Genie 2 | 像素生成路线：3D 世界，10-20s 一致性 |
| 2025.01 | Cosmos | NVIDIA 世界基础模型平台：扩散+自回归双路线 |
| 2025.06 | V-JEPA 2 | JEPA + 动作条件化：62h 机器人数据实现零样本规划 |
| 2025.08 | Genie 3 | 实时 720p@24fps 交互式世界，1 分钟一致性 |

## 1.3 走向统一：VLA + 世界模型的融合趋势

2025-2026 年最显著的趋势是 VLA 和世界模型走向融合：

**趋势1：世界模型为 VLA 生成合成训练数据**

NVIDIA 的 GR00T Blueprint 是典型范例——用 Cosmos 世界基础模型从少量人类演示生成 78 万条合成轨迹（等价于 6500 小时人工演示），仅用 11 小时计算。合成数据与真实数据混合后，GR00T N1 性能提升 40%。

**趋势2：世界模型作为 VLA 的"系统2"规划器**

V-JEPA 2 展示了这一路线：在潜在空间中搜索使预测状态接近目标状态的动作序列，然后交给 VLA 执行。规划耗时 16 秒/动作，比基于 Cosmos 像素生成的 4 分钟快 15×。

**趋势3：VLA 内嵌世界模型能力**

π0 的 flow matching 动作头实际上隐式学习了动作的多模态分布——即在给定观测下，"多种合理动作"的概率分布，这本身就是对世界动作空间的建模。

**趋势4：双系统架构**

GR00T N1 的双系统设计（System 1 VLM 慢思考 + System 2 DiT 快动作）是 VLA+世界模型融合的工程化实现。System 1 理解场景和高层意图，System 2 生成高频控制命令。
