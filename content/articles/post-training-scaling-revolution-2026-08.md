# 后训练 Scaling 革命：不改基座实现 50% 提升的范式转折

## 引言：预训练不再是唯一引擎

自 2020 年 GPT-3 以来，大模型行业默认的发展路径只有一个：更大的参数、更多的数据、更贵的算力，然后预训练一遍重来。每次迭代成本数千万美元，周期长达数月。

2026 年 8 月，这个剧本被撕掉重写。

智谱 Z.ai 发布 GLM-5.3：**基座参数 744B 与 GLM-5.2 完全相同**，所有性能提升来自后训练。Terminal-Bench 3.0 从 4.6 暴涨至 28.3（6 倍），DeepSWE v1.1 从 46.2 升至 66.9（+45%），内部代码基准整体提升 50%。

同一天，DeepSeek 发布 V4-Pro-0813 正式版：DeepSWE 从 12.8 跳到 62.7（**+389%**），Terminal-Bench 2.1 从 72.1 升至 87.9。AA Intelligence Index 从 45 升至 53。

加上 Meta 时隔两年重返开源阵营（Muse Glimmer 30B）、Anthropic 冲刺 2 万亿美元 IPO——2026 年 8 月，AI 行业正在经历一次范式级的转折。

---

## 一、后训练 Scaling：从辅助轮到主引擎

### 1.1 什么是"后训练 Scaling"？

传统大模型训练分为三个阶段：

| 阶段 | 目标 | 成本占比 | 能力天花板 |
|------|------|---------|-----------|
| 预训练 (Pre-training) | 学习语言和知识表示 | 80-90% | 决定模型上限 |
| 中期训练 (Mid-training) | 长上下文、领域适应 | 5-10% | 拓展边界 |
| 后训练 (Post-training) | SFT + RLHF + 工具使用 | 5-10% | 仅打磨行为 |

过去行业默认：**预训练决定天花板，后训练只能打磨**。如果你想让模型更聪明，唯一的路是花更多钱重新预训练。

GLM-5.3 打破了这个假设。

### 1.2 GLM-5.3：纯后训练的 50% 跃升

Z.ai 在官方博客中明确写道："Scaling post-training is all we did for GLM-5.3."（后训练扩展是我们为 GLM-5.3 做的全部工作。）

具体数字：

| 基准 | GLM-5.2 | GLM-5.3 | 变化 |
|------|---------|---------|------|
| Terminal-Bench 3.0 | 4.6 | 28.3 | **+514%** |
| DeepSWE v1.1 | 46.2 | 66.9 | +45% |
| Agents' Last Exam (CLI) | 23.8 | 28.5 | +20% |
| CyberGym | 77.2% | 84.5% | +7.3pp |
| ExploitBench | 24.4% | 54.4% | **+123%** |
| GDPval-AA v2 | 1508 | 1769 | +17% |

这些提升来自：
- **更多任务环境**：数十倍于 GLM-5.2 的长程任务环境
- **更多环境类型**：终端操作、代码工程、网络安全、自动化办公
- **更长训练时间**：在 IndexShare/SAO/slime RL 栈上持续训练
- **不改基座**：同一个 744B MoE 检查点

### 1.3 DeepSeek V4 Pro 0813：DeepSWE 从 12.8 到 62.7

DeepSeek 的数据更加震撼：

| 基准 | V4 Pro 预览版 | V4 Pro 0813 | 变化 |
|------|---------------|-------------|------|
| DeepSWE | 12.8 | 62.7 | **+389%** |
| Terminal-Bench 2.1 | 72.1 | 87.9 | +22% |
| CyberGym | — | 83.3 | NEW |
| AA Intelligence Index | 45 | 53 | +18% |

DeepSWE 从 12.8 到 62.7 是**单版本最大跃升**。这意味着 V4 Pro 预览版的基座能力被严重低估——预训练赋予了模型"潜力"，但后训练才将其"激活"。

### 1.4 为什么后训练 Scaling 有效？

三个底层原因：

**原因一：预训练模型存在大量"休眠能力"**

预训练让模型学会了海量模式，但很多模式在标准 SFT 阶段未被"激活"。RL 后训练通过奖励信号，能挖掘出预训练阶段习得但未被显式调用的高级推理路径。GLM-5.3 的 Cyber 安全能力爆发就是典型案例——Z.ai 并未专门训练安全能力，但扩大后训练规模后它"涌现"了。

**原因二：长程任务环境是新的"训练数据"**

传统 SFT 用的是短问答对。Agent 时代需要的是长程、多步、带工具的任务环境——模型在真实终端中执行任务、调用 API、修正错误。这些环境的构建比传统训练数据更贵，但效果也更强。GLM-5.3 在真实终端环境中完成复杂编程任务的能力从 4.6 跳到 28.3。

**原因三：RL 算法栈的成熟**

GLM-5.3 使用了 Z.ai 自研的 RL 栈：
- **IndexShare**：高效长上下文处理，降低长程任务的训练成本
- **SAO (Sample-efficient Asynchronous Optimization)**：在长程任务上的 RL 算法
- **Slime**：大规模异步训练框架

DeepSeek 则使用 Muon 算法加速训练，以及 HCA/CSA 技术压缩 KV 缓存使百万 token 训练成为可能。

### 1.5 对行业的含义

后训练 Scaling 有效意味着：

1. **模型迭代成本大幅降低**：不需要每次花数千万美元重新预训练，同一个基座可以持续"升级"
2. **中小实验室的竞争力提升**：只要有好的任务环境和 RL 栈，744B 级模型也能追平前沿
3. **预训练投资回报周期拉长**：一个好基座可以反复使用数月甚至更久
4. **安全治理面临新挑战**：GLM-5.3 的安全能力超预期爆发，导致首次"staged release"——权重在安全加固后才开放

## 二、Meta 重返开源：Muse Glimmer 的信号

### 2.1 从 Llama 4 失利到 Muse Glimmer

2025 年 4 月 Llama 4 发布后反响不佳，Meta 随后解散 FAIR 团队，聘任 Scale AI 创始人 Alexandr Wang 领导新成立的 Meta 超级智能实验室（MSL）。Muse 系列一直是闭源 API 产品。

2026 年 8 月 10 日，扎克伯格宣布：
- **Muse Glimmer 30B** 正式开源，Apache 2.0 协议
- **Muse Spark 1.2** 权重即将开放

这是一个战略级转向。Wang 在 X 上确认："We will be releasing an open weight version of Muse Spark 1.2 soon."

### 2.2 为什么 30B 端侧模型重要？

Muse Glimmer 的定位不是聊天机器人，而是**本地 Agent**：
- 规划任务步骤
- 调用工具
- 检查自己的结果
- 从失败中恢复

这些能力此前只在云端 API 中可用。Glimmer 把它放到了 24GB 消费级 GPU 上。

技术实现：
- 30B 稠密模型，全精度需要 55GB+ 显存
- 4-bit 量化压缩至 20GB 以下
- DFlash 投机解码：RTX 5090 上 3.1x 加速（74.9 → 233.4 tok/s）
- 量化精度损失：24GB 版约 1.0%，32GB 版仅 0.2%

### 2.3 对端侧 AI 的影响

Muse Glimmer 证明了**端侧 Agent** 的可行性：
- 手机/笔记本可以运行完整 Agent 工作流
- 个人数据不离开设备
- 不需要每次调用都付 API token 费

如果 Muse Spark 1.2（AA Index 56.8，SWE-bench 86.6%）也开源，它将成为可下载的第三强编程模型，仅次于 Kimi K3（93.4%）和 DeepSeek V4 Flash（88.8%）。

## 三、Anthropic IPO：2 万亿估值的背后

### 3.1 财务数据

| 时间 | 年化营收 | 增长 |
|------|---------|------|
| 2024 年初 | ~$0.87 亿 | — |
| 2024 年底 | ~$10 亿 | 11x |
| 2025 年底 | ~$90 亿 | 9x |
| 2026 年 4 月 | ~$300 亿 | 3.3x |
| 2026 年 5 月 | ~$470 亿 | 1.6x |
| 2026 年 7 月 | **~$650 亿** | 1.4x |

8 个月 7 倍增长。Q2 2026 首次调整后营业利润转正。净收入留存率 500%。

对比 OpenAI：年化营收约 $400 亿，计划 2027 年上市。

### 3.2 Anthropic 为什么跑赢了 OpenAI？

关键差异在于商业模式：

| 维度 | Anthropic | OpenAI |
|------|-----------|--------|
| 核心客群 | 企业级 B2B | C 端消费 + B 端 |
| 产品策略 | Claude Code/Agent | ChatGPT 入口 |
| 定价策略 | 高溢价服务 | 价格战 |
| 开源策略 | 纯闭源 | 部分开源(GPT-oss) |
| 算力合作 | AWS Trainium | Azure + 自建 |

Anthropic 的 500% 净收入留存率意味着：客户用得越多，付费越多，而且留存。这是典型的企业级 SaaS 飞轮。

### 3.3 2 万亿估值意味着什么？

- 超越 SpaceX 的 1.77 万亿（2026 年 6 月上市）
- 5 年从 0 到 2 万亿，是人类商业史最快纪录
- 意味着市场认为 AI Agent 的 TAM（总可寻址市场）达数万亿美元
- 资本市场认为 AI 正在替代白领工资（数万亿美元市场）

但投资者也提出了关键质疑：面对开源模型的冲击，Anthropic 能否持续维持高收费？

## 五、趋势预判

### 5.1 后训练成为主战场

GLM-5.3 和 DeepSeek V4 Pro 0813 的数据证明：**预训练的边际收益正在递减，后训练的边际收益正在上升。**

2026 下半年的竞争焦点将从"谁的参数更大"转向：
- 谁的任务环境更多样
- 谁的 RL 算法更高效
- 谁的长程训练基础设施更成熟

### 5.2 端侧 Agent 走向主流

Muse Glimmer 30B 证明端侧 Agent 在消费级硬件上可行。预计 2026 Q4 到 2027 Q1：
- 手机端 Agent 模型（<10B）将密集发布
- DFlash/投机解码成为端侧标配
- "本地 Agent + 云端大模型"的混合架构成为主流

### 5.3 开源 vs 闭源的定价博弈

DeepSeek V4 Flash 性价比 240.6 vs Claude Opus 5 的 10.5，差距 23 倍。但 Anthropic 年化营收 650 亿美元且利润转正——证明企业客户愿意为"可靠、安全、合规"付费。

结论：**开源不消灭闭源，但会持续压低闭源的定价天花板。** 闭源的生存空间在于：前沿能力领先 3-6 个月 + 企业级合规保障 + 生态工具链。

### 5.4 安全治理新范式

GLM-5.3 的 Cyber 安全能力超预期爆发，导致首次"staged release"（安全加固后才开放权重）。Z.ai 的模型已发现 2436 个漏洞覆盖 269 个开源项目，53 个 CVE 已披露。

这意味着：
- 后训练 Scaling 可能"意外"激活危险能力
- 开源模型的安全审查流程需要重新设计
- 网络安全行业获得了一个强大的新工具（也是新威胁）

## 六、总结

2026 年 8 月的 AI 行业经历了三重转折：

1. **技术范式转折**：后训练 Scaling 从辅助轮变成主引擎，同一个基座可以反复"升级"，模型迭代成本大幅降低
2. **开源生态转折**：Meta 重返开源，六款旗舰级模型同时开放权重，开源模型质量达到历史最高点
3. **资本范式转折**：Anthropic 2 万亿 IPO 验证了企业级 AI Agent 的商业化路径，AI 从成本中心转为增长引擎

对于从业者：
- 如果你做模型：投资后训练 RL 栈和任务环境，比投资预训练更有边际回报
- 如果你做应用：端侧 Agent 的窗口已经打开，30B 级模型在消费级硬件上可用
- 如果你做投资：开源模型的商业化路径（如 DeepSeek Harness 框架）比纯闭源 API 更有增长潜力

后训练 Scaling 革命才刚刚开始。
