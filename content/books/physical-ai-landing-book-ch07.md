## 7.1 数据成本：为什么物理 AI 比语言模型难得多

语言模型有几乎无限的互联网文本，而**机器人操作数据必须一次一次真做出来**。

| 获取方式 | 成本 / 规模 |
|---|---|
| ★**人类遥操作** | **50–150 美元/小时**；熟练操作员每天约 **200+ 条高质量轨迹** |
| 场景特定数据 | 几乎无法在市场上购买 |
| 标注（尤其 6 自由度位姿） | 需要专业设备 |

**后果**：数据飞轮的启动速度远慢于大模型领域，**只有资本雄厚的公司能承担大规模数据采集基础设施**。

## 7.2 现有数据来源盘点

| 来源 | 规模 / 特点 |
|---|---|
| **Open X-Embodiment** | ★**100 万条轨迹、22 种机器人形态、34 个实验室**；核心价值是证明了**跨本体迁移可行** |
| **DROID** | 7.6 万+ 轨迹，专注灵巧操作；含多视角 RGB、腕部扭矩、关节位姿 |
| **RH20T** | 专注灵巧手，20 个复杂手部任务 |
| **遥操作自有采集** | 可控、贴合场景，但贵 |
| 仿真合成 | 见 7.3 |

## 7.3 合成数据：仿真是数据放大器

| 方法 | 说明 |
|---|---|
| **域随机化** | 随机化摩擦、质量、光照、纹理 → 策略学鲁棒性（经典且最常用） |
| **程序化生成** | 批量生成场景与任务变体 |
| ★**世界模型生成** | **Cosmos Transfer 2.5 / Predict 2.5** 等生成物理准确的合成数据，并可在仿真中评估策略 |
| **数字孪生校准** | 用真实环境数据持续校准仿真（工业部署最可靠） |

**关键认知**：仿真的价值不只是「替代真实数据」，更是**「把少量真实数据放大成大量训练样本」**。

## 7.4 ★ 真实 → 仿真 → 真实闭环

业界共识是单纯仿真数据难以复刻真实世界的复杂材质与环境变化，因此闭环必须包含真实：

```
① 收集少量真实世界数据（遥操作 / 部署现场）
        ↓
② 用真实数据校准仿真环境（数字孪生对齐）
        ↓
③ 在「校准后」的仿真里大量训练（低成本、可并行、安全）
        ↓
④ 部署回真实世界
        ↓
⑤ 采集新的真实数据（含失败样本）→ 回到 ①
```

| 环节 | 要点 |
|---|---|
| ②校准 | ★**这一步决定闭环成败**——未校准的仿真训出来的策略迁移率低 |
| ⑤失败样本 | ★**失败数据比成功数据更值钱**（对应长尾） |

## 7.5 第一人称视频：绕开遥操作瓶颈的新路径

| 事实 | 数据 |
|---|---|
| **GR00T 的 EgoScale** | 用近 **21,000 小时人类第一人称视频**预训练，覆盖 20+ 任务类别 |
| 为什么重要 | ★不需要机器人遥操作，直接从人类日常行为学「手怎么动」 |
| 数据效率悖论 | 学会人类认为简单的任务需数万小时；业界设想的 **1 亿小时第一人称视频** ≈ **150 个人一生**的观看量 |

> ★**这是当前最值得关注的数据路线**：它把数据瓶颈从「昂贵的机器人遥操作」转向「相对廉价的人类视频」，成本结构显著改善。

## 7.6 ★ 数据飞轮：借鉴自动驾驶的成熟方法论

自动驾驶是数据飞轮跑得最久的领域，其方法可直接迁移：

| 机制 | 说明 | 迁移到机器人 |
|---|---|---|
| **影子模式** | 模型在后台运行但不控制，只在「与人/系统决策不一致」时上传片段 | 机器人执行时记录模型预测与实际采用的动作，分歧即样本 |
| **触发器采集** | 车端跑轻量分类器，只在置信度低/接管/异常时上传 | 机器人：**力矩异常、抓取失败、重试**时自动记录现场 |
| **自动挖掘长尾** | 从海量日志中自动挑难例 | 从运行日志里自动聚类失败模式 |
| **自动标注** | 减少人工标注量 | 轨迹与位姿可部分自动生成 |
| **闭环迭代** | 新数据 → 重训 → OTA/更新 | 模型更新后重新部署，继续采集 |

**飞轮设计要点**：

```
部署即采集：每台运行中的机器人都是数据发生器
   → 只回传「有价值的」片段（失败、低置信、罕见）
   → 自动聚类成失败模式
   → 针对性补数据 / 调仿真
   → 重训 → 再部署
```

> ★**规模效应来源**：飞轮一旦转起来，**部署的机器越多，数据越多，模型越好，越值得部署**——这是物理 AI 最重要的复利机制，也是晚入场者的主要壁垒。

## 7.7 数据的层级与配比（参考）

| 层级 | 作用 | 占比趋势 |
|---|---|---|
| **互联网视频/图文** | 通用语义与物理常识 | 基座预训练（量大、廉价） |
| **人类第一人称视频** | 手部行为先验 | ★比重在上升（EgoScale 路线） |
| **跨本体机器人数据** | 动作可执行性 | Open X-Embodiment 类 |
| **本体自有遥操作数据** | 贴合真实任务 | 量小但关键 |
| **仿真合成数据** | 放大与长尾补齐 | ★比重在上升 |
| **部署现场失败数据** | ★最值钱，直击长尾 | 持续回流 |

## 7.8 本章要点

- ★**数据成本是物理 AI 的核心壁垒**：遥操作 50–150 美元/小时、200 轨迹/人天；飞轮启动远慢于大模型。
- 开源数据：**Open X-Embodiment 100 万轨迹/22 本体/34 实验室**（证明跨本体迁移可行）、DROID 7.6 万、RH20T。
- 仿真不只是替代真实数据，更是**放大真实数据**；关键是**数字孪生校准**。
- ★**真实→仿真→真实闭环**：校准决定成败，**失败样本比成功数据更值钱**。
- ★**第一人称人类视频**（EgoScale 21,000 小时）是绕开遥操作瓶颈的关键新路径。
- ★**飞轮机制可抄自动驾驶**：影子模式、触发器采集、自动挖长尾、部署即采集；**失败与低置信片段才回传**。
- 规模效应：**部署越多 → 数据越多 → 模型越好**，这是最重要的复利与壁垒来源。
