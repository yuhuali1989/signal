## 三个数字，说明全部问题

| 数字 | 含义 |
|---|---|
| 实验室成功率 **95%** | 受控光照、固定相机、已知物体 |
| 部署后掉到 **60%** | 光照、纹理、相机角度、物体位姿都变了 |
| 生产要求 **99.9%** | 工业可接受水平 |

**换算成体感**：95% 的准确率，对一个每小时执行数十次操作的仓库机器人来说，**意味着每天失败约 50 次**。这不是"有点不准"，这是"不可用于生产"。

> ★**这就是物理 AI 落地的核心矛盾**：demo 能跑 ≠ 产线能跑，中间隔着一个数量级的可靠性差距。

## 1. 鸿沟从哪来

| 来源 | 具体表现 |
|---|---|
| **视觉条件漂移** | 光照、反光、阴影、白平衡，仿真里有限的材质组合对不上真实无限变化 |
| **几何与视角** | 相机内外参偏差、安装误差、振动导致的位姿漂移 |
| **物体与材质** | 磨损、污渍、形变、透明/高反光物体（视觉经典难题） |
| **长尾场景** | 训练数据无法覆盖所有物理情境 |
| **接触力学** | 仿真接触模型与真实摩擦力、柔顺性差距 |

**本质一句话**：**仿真与真实之间的「域差距（domain gap）」+ 真实世界的长尾，两者叠加。**

## 2. 为什么 95% 不够

| 准确率 | 每天失败次数（按每小时 40 次操作 × 8 小时 ≈ 320 次/天） |
|---|---|
| 95% | **约 16 次** |
| 99% | 约 3 次 |
| 99.9% | 约 0.3 次 |

如果每次失败需要人工介入 5 分钟：

- 95%：每天额外 **80 分钟**人力 → 一个工位几乎需要专人守着
- 99.9%：每天 **1.5 分钟** → 可忽略

> ★**ROI 必须按「有效产能」算，而不是实验室成功率算。** 这是甲方最容易踩的坑。

## 3. 数据侧：真实 → 仿真 → 真实闭环

业界共识：单纯仿真数据难以复刻真实世界的复杂材质与环境变化，因此闭环必须包含真实：

```
① 采集少量真实数据（遥操作 / 部署现场）
        ↓
② 用真实数据校准仿真环境（数字孪生对齐）
        ↓
③ 在校准后的仿真里大量训练（低成本、可并行、安全）
        ↓
④ 部署回真实世界
        ↓
⑤ 采集新的真实数据（★含失败样本）→ 回到 ①
```

四种主流 Sim2Real 方法：

| 方法 | 做法 | 评价 |
|---|---|---|
| **域随机化** | 随机化摩擦、质量、光照、纹理，逼策略学鲁棒性 | ★最经典、应用最广 |
| **师生蒸馏** | 仿真中训练有**特权信息**的教师，蒸馏到只能用真实传感器的学生 | 有效，需两阶段训练 |
| **数字孪生实时校准** | 用视觉持续监控真实环境，动态调仿真参数与之同步 | ★**工业部署中最可靠** |
| **真实→仿真→真实闭环** | 少量真实 → 校准仿真 → 大量训练 → 部署 → 再采集 | 持续改进循环 |

## 4. 架构侧：分层 + 精度分层

| 手段 | 做法 |
|---|---|
| **系统 1 / 系统 2 分层** | VLA 管快反应（毫秒级），世界模型/大模型管深思（秒级） |
| ★**精度分层** | 粗操作（找、抓）给 VLA/VLM；**精定位（对准、插入）还给传统视觉 + 力控** |
| **端云分工** | 端侧跑实时小模型；云端跑深思大模型 |

> 精度分层是性价比最高的一招：**不要指望一个模型从粗到精全包**，传统方法在结构化高精度场景里比大模型更准、更快、更可验证。

## 5. 安全侧：硬约束 + 降级

| 兜底层 | 做法 |
|---|---|
| **硬约束** | 速度/力矩/空间限位、急停 —— ★**不经过模型，硬件/固件直接生效** |
| **不确定性触发** | 模型低置信 → 降级 |
| **降级路径** | 保守策略（慢速、小步长）→ 传统控制 → 安全停机 |
| **人工接管** | 遥操作通道常备（同时用于数据采集） |

> ★**不要用模型保证安全，用架构保证安全。**

## 6. 评估侧：怎么才算「能用」

四条硬指标（缺一不可）：

| 指标 | 要求 |
|---|---|
| **① 全量成功率** | 报告 N 次试验的完整分布，★**禁止 cherry-pick** |
| **② 分档成功率** | 已知物体 / 未知物体 / 未知环境三档分别报 |
| **③ ★MTBF** | 连续运行 8 小时的稳定性（单次成功率会骗人） |
| **④ 恢复能力** | 失败后自恢复率、平均恢复时长、是否需人工 |

> ★**行业公开的秘密**：研究者会「从 100 次失败里挑最好看的那次演示」，1% 成功率的研究很常见。**看到演示先问：成功率怎么算的、试了多少次。**

## 7. 落地 Checklist

```
□ 延迟预算已定（控制频率 Hz → 单步 ms 预算）
□ 架构按预算倒推选定（非按版本号）
□ 能力已探测（非仅比对版本号）
□ 端侧可断网独立安全运行
□ 硬约束不经过模型
□ 有不确定性估计 + 明确降级路径
□ 评估协议写死：全量成功率 / 分档 / MTBF / 恢复
□ 每次失败回流训练
□ ROI 按有效产能（含恢复时长）折算
```

## 8. 本章要点

- ★三个数字：**实验室 95% / 部署 60% / 生产要求 99.9%**——这就是鸿沟的量化描述。
- 鸿沟来源：**域差距（光照/纹理/相机/接触力学）+ 真实世界长尾**。
- 数据侧：**真实→仿真→真实闭环**，其中**数字孪生实时校准最可靠**（工业部署）。
- 架构侧：**系统 1 + 系统 2 分层**，★**精度分层（精定位还给传统方法）**。
- 安全侧：★**硬约束不经过模型** + 降级兜底 + 人工接管。
- 评估侧：**全量成功率 / 分档 / MTBF / 恢复能力**，★**禁止 cherry-pick**。
- ROI 按**有效产能**（含恢复时长）折算，别用实验室成功率。
