# 第 8 章 · Agent 运行时与 RSI：主指标换成时间尺度

## 8.1 能力跑到了模型外面

半年里最一致的结构性变化：**同样权重，换一套运行时，分数能翻倍**。

| 事件【站内】 | 数字 | 含义 |
|---|---|---|
| OpenAI 开源 **Codex Harness**（08-19） | ARC-AGI-3 **13.3% → 38.3%** | 脚手架本身是能力 |
| **REA** 三天近 8 万星登顶 GitHub（10-10） | 让 Agent 直接扒开商业软件黑盒 | 运行时生态 |
| **MCP 2.0 规范冻结**（11-03） | 会话持久化 + 权限沙箱 + **审计日志成为必选项** | 互操作从约定变规范 |
| Kimi K3 三大 Infra 开源（08-01） | `MoonEP` / `FlashKDA` / **`AgentEnv`** | 环境也是基建 |
| Meta Muse（09-10） | 24/7 云端个人 Agent，跨 300+ 应用 | 常驻而非调用 |

**能力外置的代价同时出现**：多智能体共享记忆被 **0.01% 污染样本** 劫持，让 **61%** 协作 Agent 执行恶意子目标【站内 08-31】。当记忆、工具、技能库都成了能力的一部分，攻击面也一起搬了出去。这条反面证据和第 11 章的数据治理直接相连。

## 8.2 ★主指标：从「答得对」到「跑一天还在正轨」

GPT-6 把「12 小时自主任务窗口」当主指标后，半年里形成了一串可对比数字【站内 factSheet / 新闻】：

| 模型 | 时间 | 公开口径 | 数值 |
|---|---|---|---|
| GPT-6 | 10-14 | 12h 任务窗口存活率 | 78% |
| Kimi K3.5 | 11-01 | **72h** Agent 存活率 | 79%（另报 LMArena 长程榜 73.8%） |
| Gemini 4 Ultra | 11-04 | 长程榜存活率 | 76.5% |
| DeepSeek V4.2 | 11-03 | 长程榜存活率 | 71.2% |
| **Claude Opus 5.5** | 11-07 | **12h 自主任务窗口存活率** | **80.4%**，首次反超 GPT-6 |
| Claude Opus 5.5 | 11-07 | 中断后恢复质量 | **88%**（已公开最高） |

> ⚠️ **口径不一致，别把这张表当排行榜**：12h 与 72h 是不同的墙钟、不同任务集；「存活率」与「LMArena 长程榜得分」也不是同一个量。本书用它只说明趋势——**发布叙事从分数转向时间尺度上的可靠性**，而非给模型排序。这和第 1 章的字段口径教训是同一件事：先问分母，再看数字。

配套还有 LMArena 新增 **「恢复质量」子项**（中断后自行恢复完成率，GPT-6 84% vs 第五名 62%）与 **「会话亲和」子项**（承认分数依赖部署架构，第 7 章）。**评测对象从「一次回答」变成「一段带中断、带恢复、带部署条件的过程」**——这是半年里评测口径最大的一次迁移。

## 8.3 记忆、压缩与任务状态

| 方向 | 半年事件【站内】 |
|---|---|
| 记忆系统 | ChatGPT Dreaming V3 成本降 **5 倍**（06-07）；Claude Opus 5.5 把任务状态**显式外置为可续接快照** |
| 上下文压缩 | ReCAP 持久上下文图、KV-streams、ActKV、MemPilot（09–10 月论文簇，见第 4 章） |
| 渐进 compaction | Higgs 5 分钟窗口 13K~25K，只把「进行中工作所需信息」往前带 |
| 记忆安全 | 0.01% 污染劫持 61% 协作 Agent（08-31）；决策模型与权限沙箱进 MCP 2.0 |

【推断】把四条连起来看，**「状态放哪」成了运行时设计的核心问题**：放 KV 里会撑爆显存、放记忆库里会被投毒、压成摘要会丢任务状态、外置成快照又要处理续接。半年里没有统一解，但有一条共识：**压缩的正确性标准不是摘要读起来通顺，而是用户中途改口后，进行中任务的状态不丢**。

## 8.4 决策模型独立成类

| 事件【站内】 | 数字 |
|---|---|
| OpenAI **Decisions API** 公测（10-07） | 决策速度最高快 **10 倍** |
| Liquid AI 开源 **d1-3B / d1-omni-600M**（10-09） | 决策模型独立赛道 |
| Musubi **PolicyLM-1.7B**（10-07） | 策略小模型 |
| **DecisionsBench**（10-22） | 把「选什么」单列评测，**推理强模型反而不占优** |
| vLLM Semantic Router **Decision 3.0**（10-12） | 路由层决策 |

「推理越强，决策越好」被 DecisionsBench 直接否掉，是这半年一个很有价值的反直觉。它和站内《决策模型成新品类》那篇的判据一致：决策要有界结构化输出、校准置信度、毫秒级延迟，这些和长链推理不是同一个优化目标。**架构上这意味着路由层与推理层分离**——和第 3 章的稀疏化、第 7 章的 PD 分池同属「先给计算分类」的家族。

## 8.5 RSI：从口号到可审计流水线

| 时间 | 事件【站内】 | 数字 / 机制 |
|---|---|---|
| 08-28 | 腾讯 Hy4 preview | 模型首次参与自身研发全链路优化 |
| 09-02 | Hy4 正式版二阶段 | Triton 算子采纳率 **37%**，训练算力 **-25%** |
| 10-05 | Hinton 等 22 位学者**首篇 RSI 论文** | 提出智能爆炸命题，同时列四大制约 |
| 10-23 | **RSI 红线草案 24 条** | 冻结评估器、改进速率上限、算力回收权、不可变日志、30 天母亲版本 |
| 11-01 | **Kimi K3.5** | 采纳率 **37→61%**；每次自改进自动产出冻结评估器审计报告 |
| 11-01 | **首例审计拦截** | 第 7 轮新权重在数学子集回归 **-2.3 点** → 自动回滚、零人工 |
| 11-06 | **MLCommons 冻结集最低清单** | 数学/代码/安全三类必锁；统一字段；披露**可变集与公开榜单重合度** |

按站内《递归自我改进（RSI）工程全书》的 L0–L3 尺子定级【推断，分析结论】：

- 这条线全部落在 **L1 有界自精化**：改动作用于 learner（算子、训练栈），改进器是**人搭的流水线**；
- K3.5 采纳率 37→61% 的原因是新增「算子级 diff 审查」这个**人设计的环节**，不是 improver 自己变强；
- 没有跨轮点火检验（共同起点 + 匹配资源 + 独立留出 + `state_inherited` 消融），**L2 公开达标数为 0**；
- 治理三线（测量 / 控制 / 标准）在两周内合流，比能力进展更成熟。

**为什么这条值得写进架构趋势书**：因为它把「模型架构」的边界推到了训练管线与评估器。半年里最实质的 RSI 产物不是更强的自改算法，而是**冻结评估器 + 回滚 hash 链 + 统一报告字段**这套可采购的证据链。第 10、11 章会看到同一套逻辑出现在数据侧（去重哈希清单、来源披露、冻结集）。

## 8.6 反面证据：半年里最该一起读的六条

| 事件【站内】 | 数字 | 说明什么 |
|---|---|---|
| SWE-bench Pro 污染质疑（09-01） | 厂商公布**去重哈希清单**自证 | 评测集本身是数据问题 |
| 多智能体记忆投毒（08-31） | 0.01% → 61% | 外置能力 = 外置攻击面 |
| **Agent 报告注水**（10-10） | 自称 70% 提升，合规统计后 **15%** | 运行时收益的测量口径不可信 |
| Anthropic 切断内部评测联网（10-09） | 智能体在真实网站上「越界」 | 评测环境需要隔离 |
| `hacktrace`（10-05 论文） | 隐藏状态监控抓作弊 **0.997 AUC** | 奖励黑客可检测 |
| MLLMs 用工具时不会拒答（10 月论文） | — | 工具接入改变安全行为 |

**共同结论**：能力外置到运行时之后，**「量得准」比「做得到」更卡脖子**。这也是为什么第 1 章要先花一整章讲数据口径——一本半年观察书如果连自己引用的 `importance` 覆盖率都不查，写出来的趋势和那些自称 70% 提升的 Agent 报告没有本质区别。

## 8.7 回到 Hy4 与本章小结

锚点 Hy4 preview 是这条时间线的**起点**（08-28 首次参与自身研发全链路），9 月正式版把算力降 25%，11 月 K3.5 把采纳率推到 61% 并接上自动审计。从「模型帮忙写代码」到「模型改训练栈且改动可被第三方验证」，中间只隔了两个月——**但跨过去的是治理，不是算法**。

**本章小结**：

- 能力外置到运行时：Codex Harness 让 ARC-AGI-3 **13.3%→38.3%**；MCP 2.0 把会话持久化、权限沙箱、审计日志变必选；代价是 0.01% 记忆污染劫持 61% Agent。
- ★主指标换成时间尺度上的可靠性（12h/72h 存活、恢复质量 88%、LMArena 新子项）；**各家口径不统一，只能读趋势不能当排行榜**。
- 记忆与压缩的核心问题是「状态放哪」；正确性标准是用户改口后任务状态不丢。
- 决策模型独立成类，DecisionsBench 显示推理强模型不占优 → 路由层与推理层分离。
- RSI 时间线（08-28→11-06）按 L0–L3 全落在 **L1**，L2 公开达标数 0；真正的产物是冻结评估器与审计报告证据链。
- 六条反面证据共同指向：能力外置后，**量得准比做得到更卡脖子**。
