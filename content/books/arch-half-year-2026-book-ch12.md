# 第 12 章 · 七条趋势、一笔成本账与未来半年的观察指标

## 12.1 七条趋势（每条都带反例）

| # | 趋势 | 硬证据【站内/报告】 | 反例 / 边界 |
|---|---|---|---|
| 1 | **容量涨、单步不涨** | 总参 770B→2.4T，激活稳在 15~49B，激活比收敛 **4.6~6.4%**；Mistral 1.05T 仅 4000 GPU 训练 | 小模型 Mellum 12B/2.5B 激活比 20.8%；Dust 无反向传播、扩散语言模型等分叉仍在 |
| 2 | **时间结构被显式建模** | Higgs **160ms chunk** 六条泳道；GPT-6 **12h** 任务窗口；Figure Helix 2 System 2 降到 **1Hz** | 各家存活率口径不统一（12h / 72h / 榜单分），不可当排行榜 |
| 3 | **上下文优化前移到预算与 compaction** | 每片约 7 token、**2.6K/分钟**、5 分钟 **13K~25K**；优先级压预算→compaction→KV 剪枝 | 【推断】朴素 1M 上下文 KV 仍要约 122GB，长上下文仍需稀疏注意力 + GQA |
| 4 | **能力外置到运行时** | Codex Harness 让 ARC-AGI-3 **13.3→38.3%**；MCP 2.0 审计日志必选；决策模型独立 | 0.01% 记忆污染劫持 61% Agent；Agent 报告自称 70% 提升实为 15% |
| 5 | **主干「两端分、中间合」** | 冻结 T5/UmT5、参考条件只进 decoder、对齐冻 LLM、像素解码外置 | Emu3 等统一离散路线仍在，判据是「要不要统一符号空间」而非对错 |
| 6 | **训练配方与数据披露变成规格** | 14.8T token / MuonScale、**8σ** FP8 回退阈值、**62→48→55%** 配比、白名单制、CANN 缺口清单 | 50% 是观测值不是常数；披露仍多为自愿，跨厂商不可直接比 |
| 7 | **评测量的是过程，不是一次回答** | 12h 存活 80.4% / 恢复质量 88% / 全深度召回 / 会话亲和子项 / 可变集重合度 | `ad-vla` 越小越好、`video-gen` 越大越好，跨榜比较前先确认方向 |

**七条里有一条主线贯穿**：算力不再无限，于是架构（1、3、5）和数据（6）一起被要求「省得有依据」，而省下来的复杂度被搬到运行时与时间轴（2、4），最后逼着评测口径跟着改（7）。

## 12.2 一笔成本账

| 数字【站内】 | 含义 |
|---|---|
| token 单价降 **89%**，推理总支出涨 **3.2 倍** | 调用量涨得比单价降得快 |
| DeepSeek V4-Flash 成本仅顶级 **1/100**；V4.2 性价比榜 **292.0** | 单 token 报价的竞争 |
| Higgs 设计目标：1 小时模型 ≤ 人工 **1/10** | 长会话的成本上限 |
| Rubin CPX 按 **1:3** 分池，同功耗 **+1.9×** | 用硬件分类换吞吐 |
| Ray 3.0 离线批 GPU 利用率 **61→95%** | 用调度喂满换吞吐 |

> 【推断】**主战场已经从「单 token 报价」移到「一次任务总共烧多少 token、多少卡时、多少常驻副本」**。全双工持续 decode、长程 Agent、多副本常驻都在放大分母，所以第 3 章压激活比、第 4 章压上下文、第 6 章并行换时间、第 7 章分池与副本摊薄，本质上都是同一笔账的四个科目。

## 12.3 五个反直觉

1. **参数越做越大，单步反而更便宜**——因为涨的是总参（存储换容量），不是激活（决定单步）。
2. **同样权重换个 Harness 分数翻倍**（13.3→38.3%），所以「模型能力」不再等于「模型权重的能力」。
3. **1M 上下文先实现，尾部召回后修**（Hy4 08-28 → Gemini 4 11-04，隔两个月），能力先到、可靠性后补是常态。
4. **推理越强，决策不一定越好**——DecisionsBench 显示推理强模型反而不占优，路由与推理要分层。
5. **数据 ×10 只换来跨场景第 5 个场景 13% 的边际收益**——买得到单场景成功率，买不到泛化。

## 12.4 未来半年该盯的八个指标

| 指标 | 怎么算 | 防什么造假 |
|---|---|---|
| 激活比 | 激活参数 / 总参 | 只报总参不报激活 |
| 每片/每分钟 token 预算 | 片长 × 每片槽位 | 只报「上下文长度」不报持续成本 |
| 长程存活率 | 统一墙钟 + 统一任务集 | 12h 与 72h 混着比 |
| 恢复质量 | 中断后自行恢复完成率 | 只报「未中断」的漂亮轨迹 |
| 全深度召回 | 分段 needle，不只首尾 | 只测首尾两个位置 |
| 跨场景泛化边际 | 第 5 个场景收益 / 第 1 个 | 用单场景成功率外推 |
| 冻结集重合度 | 可变集 ∩ 公开榜单 | 在可变集上讨好准入评测 |
| 数据披露完整度 | 配比 / 去重 / 来源 / 许可字段覆盖率 | 只给一个 token 总数 |

最后一行是第 1 章那次自查的直接产物：**连本站自己的 `importance` 都只有 55.8% 覆盖、`platform` 只有 5.4%**，凭什么相信外部报告的每个字段都齐？先把分母查清楚，是所有趋势判断的前置条件。

## 12.5 选型决策表

| 你的场景 | 优先选 | 别做 |
|---|---|---|
| 长会话 / 全双工服务 | 低压每片预算 + 渐进 compaction + 会话亲和路由 | 先上 KV 剪枝、轮询分发 |
| 大规模多模态预训练 | WebDataset + Energon；浮点特征另存 npy/tar | 把 ViT float32 硬塞 bin/idx |
| 统一离散符号空间 | 统一词表 + logits mask；词表 >65536 用 int32 | 默认 uint16、默认 8192 码本 |
| 视频生成 / 实时出画面 | 3D 因果 VAE + DiT，CFG/VAE 并行 | 逐帧 2D VQ（闪烁、坍缩、泄漏） |
| Agent 上线 | 冻结评估器 + 回滚链 + 审计报告 + 记忆写入验收 | 让 LLM Judge 当准入 oracle |
| 具身 / VLA | 先建数据引擎与真实工况回流 | 只堆 VLM 基座参数 |
| 国产算力迁移 | 公开算子缺口清单 + EP 通信基准 | 只宣布「已适配」 |

## 12.6 全书十条结论

1. 这半年的主线不是堆参数，是**稀疏化 + 时间结构 + 上下文成本**三件事同时收紧。
2. 数据侧同步从「有多少」转向「**配比、口径、可追溯**」，两件事是同一笔算力账。
3. 激活比收敛到 4.6~6.4%，细粒度专家（256→24576）与 EP 通信（373GB/s）是配套工程。
4. 1M 上下文成基线后，竞争点在尾部召回（82→97%）与全深度测试，不在标称窗口。
5. 语言部分的最佳实践已公开：对齐冻、SFT 以 1/20 LR 解冻、文本配比先降后升。
6. 生成侧收益主要来自**并行与分层**（CFG-Parallel、Parallel VAE -41%、冻结 T5），不是新损失。
7. PD 分离下沉到硬件 1:3 分池；FP8 从推理走进全量训练且公开稳定性阈值。
8. 能力外置到运行时（Harness / MCP / 决策层），主指标换成时间尺度上的可靠性。
9. RSI 半年成果全在 **L1 有界自精化 + 可审计证据链**；L2 公开达标数为 0。
10. ★**数据分布决定能力上限，架构只给边界让路**——caption、遥操作轨迹、冻结集、白名单，说的都是同一件事。

## 12.7 一句话收尾

> **2026 年 5→11 月，模型架构的进展看起来像「模型变强了」，实际上是「把算力、时间、状态和数据分别放到了更合适的位置」；而能不能证明它变强，越来越取决于你这本账记得全不全。**
