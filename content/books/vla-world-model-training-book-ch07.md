# 第 7 章：世界模型三大范式——JEPA、像素生成与自回归

## 7.1 三大范式的根本分歧

世界模型的核心问题是："给定当前观测和动作，如何预测未来状态？"三种范式对这个问题的回答截然不同：

```
范式 1: JEPA（潜在空间预测）
  "不要预测像素，预测抽象表示。"
  代表: V-JEPA 2 (Meta)

范式 2: 像素生成（扩散模型）
  "生成未来每一帧的像素。"
  代表: Cosmos (NVIDIA), Genie 3 (DeepMind)

范式 3: 自回归（Next-Token 预测）
  "把视频变成 token 序列，预测下一个 token。"
  代表: Cosmos 自回归版, Sora-like 模型
```

| 维度 | JEPA | 像素生成 | 自回归 |
|------|------|----------|--------|
| 预测空间 | 潜在表示 | 像素空间 | 离散 token 空间 |
| 训练信号 | L1 距离（潜在空间） | 去噪 MSE | 交叉熵 |
| 可视化输出 | ❌ 需要额外解码器 | ✅ 直接输出视频 | ✅ 解码 token→视频 |
| 训练效率 | 最高（不需生成细节） | 最低（需生成每像素） | 中 |
| 推理速度 | 最快（单次前向） | 慢（多步去噪） | 中（自回归步数） |
| 物理一致性 | 好（学高层次概念） | 中（可能生成不存在的细节） | 中 |
| 可用于合成数据 | ❌ 不能直接输出视频 | ✅ 天然适合 | ✅ 适合 |

## 7.2 范式一：JEPA（潜在空间预测）

### 7.2.1 理论基础

JEPA（Joint Embedding Predictive Architecture）由 LeCun 于 2022 年提出。其核心论点：

> **智能系统应该在抽象的表示空间中预测，而非在像素空间中重建。**

原因：像素级预测被迫学习不可预测的噪声细节（草地纹理、光线反射），浪费模型容量。潜在空间预测只学习高层次可预测的概念（物体未来位置、运动轨迹）。

### 7.2.2 V-JEPA 2 的架构

```
┌─────────────────────────────────────────────────┐
│               V-JEPA 2 架构                      │
│                                                   │
│  输入视频 → [编码器 E_θ] → 潜在表示 z              │
│              (ViT-g, 1B参数)                      │
│                                                   │
│  上下文 z_context + mask 信息                     │
│       ↓                                           │
│  [预测器 P_φ] → 预测表示 ẑ_predicted              │
│  (ViT-s, 22M参数)                                │
│                                                   │
│  目标: z_target = EMA_E(x_target)  (stop-grad)   │
│  损失: L = ||ẑ_predicted - z_target||₁            │
└─────────────────────────────────────────────────┘
```

### 7.2.3 关键技术细节

**3D-RoPE 位置编码**：

V-JEPA 2 使用三维旋转位置编码（时间 × 高度 × 宽度），取代了 V-JEPA 1 代的绝对正弦编码。3D-RoPE 的优势在于自然编码了时空关系，且对大模型训练更稳定。

**Tubelet Patchify**：

视频被切分为 2×16×16（T×H×W）的管状切片，而非 2D patch 的简单堆叠。这保留了时间维度的局部性。

**Multiblock Masking**：

训练时对视频进行多块掩码——同时掩码多个时空区域，预测器需要从上下文推断被掩码区域的表示。

**防止表示坍缩**：

JEPA 的最大风险是表示坍缩——编码器输出常数，预测器也输出常数，损失为零但什么都没学到。V-JEPA 2 用两个技术防止：
1. **EMA 编码器**：目标表示由编码器的指数移动平均（EMA）版本计算，参数不更新（stop-gradient）
2. **仅在 masked patch 上计算损失**：不是全部 patch 的表示都要预测，只有被掩码的

### 7.2.4 四个关键扩展要素

V-JEPA 2 从 V-JEPA 1 升级，有四个关键改进：

| 要素 | V-JEPA 1 | V-JEPA 2 | 增益 |
|------|----------|----------|------|
| 数据规模 | 200万视频 | 2200万视频 (VideoMix22M) | +1.0 pp |
| 模型规模 | ViT-L 300M | ViT-g 1B | +1.5 pp |
| 训练长度 | 90K iterations | 252K iterations | +0.8 pp |
| 渐进分辨率 | 固定 256² | warmup 16f@256² → cooldown 64f@384² | +0.7 pp, 8.4× GPU-time 节省 |

**渐进分辨率的工程价值**：全分辨率训练 ViT-g 需要约 60 GPU-years；渐进策略（先低分辨率预热，再高分辨率冷却）节省 8.4× GPU 时间。

### 7.2.5 JEPA 的优势与局限

**优势**：
- 训练效率最高（不生成像素）
- 学到的表征最鲁棒（忽略不可预测的噪声）
- 冻结评估 SOTA（SSv2、Kinetics 等）
- 可用于零样本机器人规划（62h 数据微调即可）

**局限**：
- **无法直接输出视频**：不能为 VLA 生成合成训练数据
- **不能直接喂给需要像素的策略**：如果 VLA 期望图像输入，JEPA 的潜在表示需要额外解码
- **规划慢**：V-JEPA 2 零样本规划需 16 秒/动作

## 7.3 范式二：像素生成（扩散模型）

### 7.3.1 理论基础

像素生成范式认为：**要真正理解世界，必须能生成世界的视觉表现**。通过学习从噪声到清晰视频的去噪过程，模型被迫理解物理规律（重力、碰撞、物体持久性）。

### 7.3.2 Cosmos 的扩散架构

Cosmos 的扩散世界基础模型（7B/14B）采用 DiT（Diffusion Transformer）架构：

```
训练:
  1. 输入视频 → Cosmos-Tokenizer → 连续 token
  2. 给 token 加高斯噪声: x_t = α_t·x_0 + (1-α_t)·ε
  3. DiT 预测噪声: ε_θ(x_t, t, condition)
  4. 损失: ||ε_θ - ε||²

推理 (Video2World):
  1. 当前观测帧 → tokenize → 作为条件
  2. 文本提示 → T5-XXL 编码 → 作为条件
  3. 从纯噪声开始, 10-50步去噪
  4. 生成未来视频帧
```

### 7.3.3 渐进训练策略

Cosmos 采用三阶段渐进训练：

| 阶段 | 分辨率 | 帧数 | 上下文长度 | FSDP | CP |
|------|--------|------|------------|------|-----|
| 低分辨率预训练 | 512p (640×512) | 57 | 10,240 | 64 | 2 |
| 高分辨率预训练 | 720p (1280×704) | 121 | 56,320 | 64 | 8 |
| 高质量微调 | 720p | 121 | 56,320 | 64 | 8 |

上下文长度计算：`(W÷8÷2) × (H÷8÷2) × ((T-1)÷8+1)` = 720p 下 56,320 tokens。

### 7.3.4 多宽高比训练

为适应不同内容，Cosmos 将数据组织为 5 个宽高比桶：

| 宽高比 | 分辨率 | 适用场景 |
|-------|--------|----------|
| 1:1 | 640×640 | 监控、俯视 |
| 3:4 | 512×640 | 竖屏机器人视角 |
| 4:3 | 640×512 | 标准机器人摄像头 |
| 9:16 | 360×640 | 手机/手持 |
| 16:9 | 640×360 | 宽屏场景 |

不同数据并行组可以从不同桶采样，通过反射填充对齐 batch。

### 7.3.5 像素生成的优势与局限

**优势**：
- 直接输出可视化视频，天然适合合成数据生成
- 可用于 VLA 训练数据增强（GR00T Blueprint）
- 可用于闭环评估（VLA 策略在世界模型中测试）
- 3D 一致性好（Cosmos 在 RealEstate10K 上接近真实视频）

**局限**：
- 训练和推理成本高（多步去噪）
- 可能生成不存在的物理细节（"幻觉"）
- 物体持久性差（长视频中物体可能消失/突变）
- 接触动力学不准确（碰撞、挤压等精细物理）

## 7.4 范式三：自回归（Next-Token 预测）

### 7.4.1 理论基础

自回归范式将视频建模为 token 序列，复用 LLM 的 next-token prediction：

```
视频 → 离散 tokenizer → token 序列 [t₁, t₂, ..., tₙ]
训练: L = -Σ log p(t_i | t_{<i})
推理: 自回归生成 token → 解码 → 视频
```

### 7.4.2 Cosmos 自回归架构

Cosmos 的自回归世界基础模型（4B-13B）使用 Llama3-style 架构：

| 配置 | 值 |
|------|-----|
| 架构 | Llama3-style Transformer decoder |
| Tokenizer | Cosmos-1.0-Tokenizer-DV8x16x16 (离散) |
| 词汇表 | 64,000 |
| 位置编码 | 3D RoPE (YaRN 扩展) + 3D APE |
| 文本条件 | T5-XXL 交叉注意力 |
| 稳定化 | QK-Normalization + Z-loss |
| 并行 | TP + SP |
| 训练阶段 | 17帧 → 34帧 → 加文本条件 → cooling-down |

### 7.4.3 自回归的优势与局限

**优势**：
- 复用 LLM 训练/推理基础设施（KV cache, speculative decoding）
- 可与文本/语言模型统一架构
- 推理可用 Medusa 等推测解码加速（Cosmos 实现 10 FPS@320×512）

**局限**：
- 离散 token 化导致信息损失 → 像素模糊
- 需要 Diffusion Decoder 增强（Cosmos 的 Enhancer）
- 长视频生成质量下降（误差累积）
- 词汇表大小与分辨率的权衡

## 7.6 Genie 3 的混合范式

Genie 3 是一个有趣的混合体——它结合了自回归和潜在动作建模：

```
Genie 3 Pipeline:
  1. Spatiotemporal Video Tokenizer → 离散 token
  2. Latent Action Model → 从视频中推断隐式动作
  3. Dynamics Model → 自回归预测下一帧 token
  4. Renderer → token → 像素帧
```

Genie 3 的独特之处在于 **Latent Action Model**——它从无标注视频中推断"什么动作导致了帧间变化"，无需人工标注动作。这使得 Genie 3 可以从 3000 万个互联网视频片段中自监督学习，生成可交互的 3D 环境。

## 7.7 选型决策框架

```
你的世界模型需要做什么？
│
├─ 为 VLA 生成合成训练数据
│   → 像素生成 (Cosmos Diffusion)
│   → 需要: 高质量视频输出 + 物理合理性
│
├─ 为 VLA 做闭环评估
│   → 像素生成 或 自回归
│   → 需要: 可交互 + 可可视化
│
├─ 零样本机器人规划
│   → JEPA (V-JEPA 2)
│   → 需要: 高效潜在预测 + 少量机器人数据微调
│
├─ 视频理解 + 表征提取
│   → JEPA (V-JEPA 2)
│   → 需要: 冻结评估 SOTA
│
└─ 生成可交互的 3D 环境
    → 自回归 + 潜在动作 (Genie 3)
    → 需要: 实时交互 + 动作可控
```

## 7.8 小结

世界模型三大范式的核心差异在于**预测空间**的选择：

1. **JEPA 选择潜在空间**：最高效、最鲁棒，但无法直接输出视频
2. **像素生成选择像素空间**：最直观、最适合合成数据，但成本最高
3. **自回归选择离散 token 空间**：复用 LLM 基础设施，但精度受限

没有绝对最优的范式——选择取决于下游任务。下一章将深入世界模型的完整训练流程，从数据策展到后训练。
