# 第 10 章：VLA + 世界模型——联合训练、Sim2Real 闭环与未来方向

## 10.1 为什么 VLA 需要世界模型

前九章分别拆解了 VLA 和世界模型的训练过程。本章回答一个更高层的问题：**如何将两者融合为完整的 Physical AI 系统？**

VLA 的根本局限在于**无法想象**——它只能对当前观测做出反射式反应，不能预测"如果我做了X，会怎样"。这导致：

| VLA 局限 | 根因 | 世界模型如何解决 |
|----------|------|------------------|
| 无法规划长视距任务 | 只预测下一步动作 | 世界模型可预测多步未来 |
| 无法从失败中学习 | 需要真实试错（危险/昂贵） | 世界模型可安全模拟试错 |
| 数据采集成本高 | 需要真实机器人演示 | 世界模型可生成合成数据 |
| 无法评估"如果"场景 | 需要真实部署 | 世界模型可闭环评估 |
| 缺乏常识物理 | 机器人数据规模有限 | 世界模型从海量视频学习物理 |

## 10.2 四种联合范式

### 范式 1: 世界模型为 VLA 生成合成训练数据

```
                    ┌──────────────┐
  少量种子演示 ────→ │  世界模型     │ ────→ 78万条合成轨迹
  (50-200条)        │  (Cosmos)    │       (等价6500h人工)
                    └──────────────┘
                           ↓
                    ┌──────────────┐
  真实数据 ────────→ │  VLA 训练    │ ────→ 部署就绪策略
  合成数据 ────────→ │  (GR00T N1)  │       (+40% 性能)
                    └──────────────┘
```

**GR00T Blueprint 的完整流程**：

```
Stage 1: 遥操作 (种子)
  50-200 条真实演示
  ↓
Stage 2: MimicGen (仿真变体)
  仿真中自动生成 ~1000 条变体
  方法: 程序化变换 (位置/旋转/物体替换)
  ↓
Stage 3: Cosmos 神经轨迹生成 (大规模合成)
  Cosmos Predict2 WFM: 生成视频轨迹
  Cosmos Reason: 基于物理的响应
  产出: 78 万条合成轨迹
  计算: 11 小时 (vs 9 个月人工)
  ↓
Stage 4: 混合训练
  真实数据 + 合成数据 → GR00T N1 微调
  效果: 性能提升 40%
```

**数据质量验证**：

NVIDIA 使用 DreamGen Bench 评估合成数据质量——发现合成数据质量（DreamGen Bench 得分）与真实机器人性能正相关，验证了"更强的世界模型 → 更好的合成数据 → 更强的 VLA"的正循环。

### 范式 2: 世界模型作为 VLA 的规划器

```
┌──────────────────────────────────────────────────┐
│              V-JEPA 2 规划 + VLA 执行              │
│                                                    │
│  目标图像 o_goal                                    │
│       ↓                                            │
│  ┌─────────────┐    搜索动作 a_t                    │
│  │ V-JEPA 2-AC │←──使 ||P(z_t, a_t) - z_goal|| 最小│
│  │ (世界模型)   │                                   │
│  └──────┬──────┘                                   │
│         │ a_t (规划动作)                            │
│         ▼                                          │
│  ┌─────────────┐                                   │
│  │    VLA      │──→ 精确执行 a_t                    │
│  │  (策略模型)  │                                   │
│  └─────────────┘                                   │
│         │                                          │
│         ▼                                          │
│    机器人执行 → 新观测 → 回到世界模型                │
└──────────────────────────────────────────────────┘
```

**V-JEPA 2 的规划细节**：

```
输入: 当前图像 o_t, 目标图像 o_goal
  ↓
编码: z_t = E(o_t), z_goal = E(o_goal)
  ↓
规划 (每步 16 秒):
  for a_t in action_space:
    z_predicted = P(z_t, a_t)
    score = ||z_predicted - z_goal||₁
  选择 score 最小的 a_t
  ↓
VLA 执行:
  VLA 接收 (o_t, "执行 a_t") → 精确控制命令
  ↓
观测新状态 → 重复
```

**优势**：世界模型在潜在空间搜索，比像素空间快 15×（16s vs 4min）

**局限**：16 秒/动作仍远不能满足实时控制需求——适合"慢思考"阶段的任务分解，而非高频控制

### 范式 3: 双系统架构（VLM + DiT）

```
┌──────────────────────────────────────────────────┐
│              GR00T N1 双系统架构                    │
│                                                    │
│  ┌──────────────────────┐                          │
│  │  System 1: VLM (慢)   │  ~5 Hz                  │
│  │  Eagle2 VLM 2B        │                          │
│  │  输入: 图像 + 指令     │                          │
│  │  输出: 语义特征 token  │                          │
│  │  功能: 场景理解 + 意图│                          │
│  └──────────┬───────────┘                          │
│             │ 语义条件                               │
│             ▼                                      │
│  ┌──────────────────────┐                          │
│  │  System 2: DiT (快)   │  ~100 Hz+               │
│  │  Diffusion Transformer│                          │
│  │  输入: 语义token + 状态│                         │
│  │  输出: 高频控制命令    │                          │
│  │  功能: 实时运动控制    │                          │
│  └──────────────────────┘                          │
└──────────────────────────────────────────────────┘
```

**双系统的训练流程**：

```
System 1 训练 (VLM):
  预训练: 互联网图文对 (Eagle2 已预训练)
  VLA 微调: OXE 数据 + 人类视频 (LAPA)
  
System 2 训练 (DiT):
  预训练: 大规模机器人数据 (32K小时真实 + 8K小时仿真)
  后训练: 特定任务数据 (Blueprint 合成 + 真实)

联合训练:
  System 1 输出 → System 2 条件
  端到端微调: 冻结 LM, 微调视觉+投影+DiT
```

### 范式 4: 端到端联合训练（前沿方向）

```
┌──────────────────────────────────────────────────┐
│          端到端 VLA + 世界模型联合训练               │
│                                                    │
│  ┌─────────┐  ┌───────────┐  ┌─────────────────┐ │
│  │ 观测 o_t │→│  共享编码器  │→│   分支          │ │
│  └─────────┘  │ (Transformer)│  ├─→ VLA头 → a_t │ │
│                └──────┬──────┘  ├─→ 预测头 → ŝ_t+1│ │
│  ┌─────────┐         │         └─→ 奖励头 → r_t │ │
│  │ 动作 a_t │←────────┘                            │
│  └─────────┘                                       │
│                                                    │
│  损失 = L_action + λ₁·L_predict + λ₂·L_reward     │
└──────────────────────────────────────────────────┘
```

这是最前沿的方向——一个模型同时学习"做什么动作"和"预测未来状态"。优势是共享表征，劣势是训练复杂度高。目前还没有公开的大规模实现，但 π0 的 flow matching 隐式学习了动作分布，GR00T 的双系统是松耦合的近似。

## 10.3 Sim2Real 闭环

### 10.3.1 闭环架构

```
┌──────────────────────────────────────────────────────┐
│                  Physical AI 数据飞轮                   │
│                                                        │
│  ┌──────────┐                                          │
│  │ 真实部署  │──→ 失败案例收集                          │
│  └────┬─────┘                                          │
│       │ 失败数据                                        │
│       ▼                                                │
│  ┌──────────┐    种子    ┌──────────┐                  │
│  │ 针对性   │──────────→│ 世界模型  │                  │
│  │ 数据采集  │           │ (Cosmos) │                  │
│  └────┬─────┘           └────┬─────┘                  │
│       │                       │ 合成变体                │
│       ▼                       ▼                        │
│  ┌──────────┐          ┌──────────┐                   │
│  │ VLA 训练  │←─────────│ 合成数据  │                   │
│  │ (GR00T)  │          │ 78万条    │                   │

└──────────────────────────────────────────────────────┘
```

### 10.3.2 闭环的关键环节

**环节 1: 真实部署 → 失败案例**

VLA 在真实环境中执行任务，自动记录失败案例（通过任务成功判定器或人工审核）。失败案例是数据飞轮的"燃料"——它们指向了 VLA 的弱点。

**环节 2: 针对性数据采集**

对失败案例进行针对性补充采集：
- 在失败的场景中采集 50-200 条正确演示
- 变换环境参数（光照、物体位置、背景）增加多样性

**环节 3: 世界模型合成增强**

将针对性数据输入 GR00T Blueprint：
- Cosmos 生成大规模合成变体
- 11 小时 → 78 万条轨迹
- 覆盖失败场景的各种变体

**环节 4: VLA 重训练**

混合真实+合成数据重新微调 VLA：
- LoRA 微调（快速迭代）
- 或全量微调（大版本更新）

**环节 5: 仿真验证**

在 Isaac Lab 中闭环评估新策略：
- 通过 → 进入真实部署
- 未通过 → 回到环节 2

### 10.3.3 闭环的经济学

| 环节 | 传统方法 | 世界模型增强 | 加速比 |
|------|----------|-------------|--------|
| 数据采集 | 6500 小时人工 | 11 小时计算 | 590× |
| 训练迭代 | 2-3 月/轮 | 1-2 周/轮 | 8-12× |
| 仿真评估 | 手工场景 | 世界模型自动生成 | ~100× |
| 端到端 | 6-12 月 | 1-2 月 | 4-6× |

## 10.4 当前挑战与前沿方向

### 10.4.1 未解决的核心挑战

| 挑战 | 现状 | 前沿探索 |
|------|------|----------|
| **长视距一致性** | Genie 3 仅 ~1 分钟 | 更长上下文 + 分层规划 |
| **精确物理** | Cosmos 接触动力学不准 | 物理引擎融合 (Newton/MuJoCo-Warp) |
| **多模态感知** | 主要处理 RGB | RGB-D + 点云 + 触觉融合 |
| **实时规划** | V-JEPA 2 需 16s/动作 | 潜在空间并行搜索 + 量化加速 |
| **安全保证** | 无形式化安全保证 | 安全屏障 + 约束满足 |
| **跨具身泛化** | GR00T 支持多种人形 | 统一潜在动作空间 |
| **Sim2Real Gap** | 合成数据仍需真实数据混合 | 域随机化 + 域适应 |

### 10.4.2 六个前沿方向

**方向 1: 统一 VLA-世界模型架构**

将 VLA 和世界模型融合为单一模型，共享编码器但有多头输出：

```
共享 Transformer
  ├─ Action Head → a_t (VLA 功能)
  ├─ Predict Head → ŝ_{t+1} (世界模型功能)
  └─ Value Head → V(s) (评估功能)

损失 = L_action + λ₁·L_predict + λ₂·L_value
```

好处：共享表征、联合优化、一次推理获得动作和预测。

**方向 2: 潜在空间中的强化学习**

V-JEPA 2 的零样本规划是"开环"的——每步独立搜索。下一步是在潜在空间中做**闭环强化学习**：

```
在 V-JEPA 2 的潜在空间中训练 RL 策略:
  State: z_t = E(o_t)  (潜在表示)
  Action: a_t
  Reward: -||z_{t+1} - z_goal||  (潜在距离)
  Transition: z_{t+1} = P(z_t, a_t)  (世界模型预测)

优势:
  - 不需要像素生成 (高效)
  - 可在"脑中"试错 (安全)
  - 可利用预训练的世界知识 (泛化)
```

**方向 3: 世界模型 + LLM 的语言条件化**

VL-JEPA（Meta 2026）将 V-JEPA 2 编码器与语言模型对齐：

```
V-JEPA 2 编码器 (物理理解) + LLM (语言理解) = VL-JEPA

效果:
  - 8B 参数达到 SOTA 视频问答
  - 世界建模任务 65.7% (超过 GPT-4o 的 53.3%)
  - 语言作为"物理理解的解码器"
```

这验证了 LeCun 的架构构想：**物理表征是基础，语言是接口**。

**方向 4: 物理引擎与神经世界模型的融合**

NVIDIA 和 Google DeepMind 合作开发 Newton 物理引擎（MuJoCo-Warp），将可微分物理引擎与神经世界模型融合：

```
传统: 神经世界模型 (学习物理) ←→ 物理引擎 (精确但慢)
融合: 神经世界模型提供快速近似 + 物理引擎做精确校正

应用:
  - 世界模型快速生成场景
  - 物理引擎校正接触/碰撞
  - VLA 在融合环境中训练
```

**方向 5: 从人类视频中学习（LAPA）**

GR00T 1.7 的 LAPA 技术从无标记的人类视频中学习动作先验：

```
互联网人类视频 (无机器人标注)
  ↓
LAPA 潜在动作预训练
  - 从视频中推断人类动作的潜在表示
  - 学习"抓取""放置""推"等动作原语
  ↓
迁移到机器人策略
  - 潜在动作空间对齐
  - 少量机器人数据微调
```

这使得世界模型和 VLA 都能利用海量无标注人类视频，进一步降低对昂贵机器人数据的依赖。

**方向 6: 多模态融合世界模型**

当前世界模型主要处理 RGB 视频。未来需要融合更多模态：

```
输入:
  - RGB 视频 (视觉)
  - 深度图 / 点云 (3D 几何)
  - IMU / 力矩传感器 (触觉/本体感受)
  - 语音 / 声音 (听觉)

输出:
  - 多模态未来预测
  - 跨模态一致性

挑战:
  - 不同模态的频率不同 (视觉 30fps, 力矩 1000Hz)
  - 不同模态的维度差异大
  - 对齐和融合策略
```

## 10.6 全书总结

### 10.6.1 核心知识点回顾

**VLA 训练**（Part II）：
1. 数据工程是基础——遥操作质量 > 数量，OXE 提供跨具身基础
2. 动作表征决定架构——离散 token / Diffusion / Flow Matching 三选一
3. 三阶段训练——VLM 预训练 → VLA 预训练 → 任务 LoRA 微调
4. Co-fine-tuning 防遗忘——50% VLM + 50% 机器人数据
5. 四大模型演进——RT-2(55B) → OpenVLA(7B) → π0(3.3B) → GR00T(2B)，效率持续提升

**世界模型训练**（Part III）：
1. 三大范式——JEPA(潜在预测) / 像素生成(扩散) / 自回归(token)，选择取决于用途
2. 数据策展是天花板——从 2000 万小时到 1 亿片段的 7 步管线
3. Tokenizer 是压缩器——Cosmos-Tokenizer 的因果时间设计是关键
4. 渐进训练省 8.4×——先低分辨率预热，再高分辨率冷却
5. 动作条件化是转化——将"世界观察者"变为"可控模拟器"

**联合训练**（Part IV）：
1. 世界模型为 VLA 生成数据——GR00T Blueprint 590× 加速
2. 世界模型做规划器——V-JEPA 2 潜在空间搜索
3. 双系统架构——VLM 慢思考 + DiT 快动作
4. Sim2Real 闭环——部署→失败→采集→合成→重训练→仿真验证→部署
5. 未来方向——统一架构、潜在RL、多模态融合、物理引擎融合
