# RT-2 论文深度解读：把互联网知识塞进机器人控制的 VLA 范式

> 选自《Signal 论文解读》系列 · 物理 AI 方向
> 论文：RT-2, arXiv:2307.15818（Google DeepMind / Google Robotics, 2023-07）

## 一、论文基本信息

| 项目 | 内容 |
|------|------|
| 标题 | RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control |
| 团队 | Google DeepMind / Google Robotics（Brohan, Ichter, Levine, Finn 等） |
| 发表 | 2023-07-28 |
| 核心贡献 | 提出 **VLA（Vision-Language-Action）范式**：把机器人动作当作"另一种语言 token"，与网页视觉-语言数据联合微调 |
| 评测量级 | **6000 次**真实机器人评测试验 |
| 模型实例 | RT-2-PaLI-X（5B / 55B）、RT-2-PaLM-E（12B） |

RT-2 是**物理 AI / 具身智能**的里程碑。它回答了一个核心问题：**互联网上学到的海量视觉-语言知识，能不能直接"迁移"到真实机器人动作上？** 在此之前，机器人策略（policy）通常是独立训练的——用机器人轨迹数据训一个只能干特定任务的网络，和"见过全世界的"语言模型完全割裂。RT-2 的突破是：让同一个模型**既会聊天、又会拧瓶盖**。

## 二、背景：为什么机器人需要"大模型"

传统机器人学习方法（包括 RT-1，RT-2 的前身）的痛点：

1. **数据稀缺**：真实机器人演示数据极其昂贵（需真人遥控采集），规模远小于互联网图文。
2. **泛化差**：在训练时没见过的物体/指令上直接崩溃。
3. **无推理**：无法理解"拿最小的那个""当作锤子用的石头"这类需要世界知识的指令。

而视觉-语言模型（VLM）恰好补齐这三块短板——它们见过亿级图文，懂得语义、常识、推理。RT-2 的核心命题：**把 VLM 直接变成机器人控制器**。

## 三、VLA 范式：动作即 token（重点）

### 3.1 关键洞察

VLM 的词汇表（vocabulary）里已经有成千上万个"词 token"。RT-2 的做法惊人地简单：**把机器人动作也编码成 token，追加进同一套词汇表**。于是"自然语言回答"和"机器人动作"在模型眼里没有任何区别——都是一串 token。

### 3.2 动作如何变成 token

机器人动作通常是一个连续向量，例如 7 维：

```
action = [x, y, z, roll, pitch, yaw, grip]   # 末端执行器位移+旋转+夹爪
```

RT-2 将其**离散化**为 token：

```
1. 每个连续维度归一化到 [-1, 1]
2. 离散成 N 个 bin（如 256 个），映射到 token id
3. 拼接成 "动作字符串"：如 "<a0> <a1> ... <a6>"
4. 这些 <a*> token 作为新词加入 LLM 词汇表
```

```python
# 动作离散化示意
def discretize_action(a, bins=256, low=-1.0, high=1.0):
    a_clip = torch.clamp(a, low, high)
    ids = ((a_clip - low) / (high - low) * (bins - 1)).round().long()
    return ids   # 每个维度 → 一个 token id (0..255)

# 训练时：动作序列作为"另类文本"拼进目标
target_tokens = text_tokens + [ACTION_TOKEN_BASE + d for d in discretize_action(action)]
```

这样一来，模型输出"这段文字"就是在输出"机器人该怎么动"。

### 3.3 为什么这个设计优雅

| 传统方案 | RT-2 方案 |
|---------|----------|
| 动作头是独立回归网络 | 动作就是 LLM 下一个 token |
| 视觉-语言与动作割裂 | 同一模型、同一词汇表 |
| 需为动作单独设计输出层 | 复用 VLM 全部参数 |

## 四、数据管道：网页数据 + 机器人数据联合（重点）

RT-2 的训练数据是**两类异质数据的混合**，这是"数据引擎"的核心：

```
┌─ 网页视觉-语言数据 (Web VLM data)
│     ├─ Visual QA (视觉问答)
│     ├─ 图文描述 / 推理
│     └─ 来自 PaLI / PaLM-E 的预训练语料
│     → 提供：语义、常识、推理、世界知识
│
└─ 机器人轨迹数据 (Robot data)
      ├─ RT-1 数据集 (真实机械臂演示)
      ├─ 自然语言指令 + (图像, 动作) 对
      → 提供：视觉→动作的映射、具体技能
```

### 4.1 联合微调（Co-fine-tuning）

RT-2 在**已经预训练好的 VLM** 上做联合微调：
- 输入：图像 + 文本指令
- 输出：要么是自然语言回答（网页数据样本），要么是动作 token（机器人样本）
- 两类样本**混合成一个训练 batch**，同一套 loss（下一 token 预测）

```
VLM (PaLI-X / PaLM-E, 已在网页数据上预训练)
        │
        │  联合微调 (co-fine-tune)
        │    ├─ 50% web VLM 样本  → 学语言/推理
        │    └─ 50% robot 样本     → 学动作映射
        ▼
RT-2: 一个既能对话、又能控制的端到端模型
```

### 4.2 数据配比的工程意义

这里的数据管道启示极其重要（呼应我们《多模态数据处理》中"概念平衡"一节）：
- **机器人数据稀缺但关键**，网页数据海量但"不会动"。
- 若只训机器人数据 → 退化为 RT-1，无泛化。
- 若只训网页数据 → 不会动。
- **混合训练让知识"迁移"**：网页上学到的"瓶子""抓握"概念，被复用为机器人抓瓶子的能力。

## 五、涌现能力与思维链

### 5.1 涌现能力（Emergent Capabilities）

RT-2 展现出**远超训练分布**的能力：
- **符号理解**：指令"把苹果放到数字 3 旁边"——数字 3 从未出现在机器人训练数据里，但模型从网页学会了数字概念并迁移。
- **人类识别**：按"穿蓝色衬衫的人"抓取，无需训练时见过该人。
- **语义推理**：指令"拿最小的物体""拿离苹果最近的物体"——需要比较/关系推理。

### 5.2 思维链（Chain-of-Thought）推理

RT-2 可先做**语言层面的推理**，再输出动作：

```
指令: "拿一个能当临时锤子用的东西"
模型内心: "锤子用来敲，石头坚硬可敲 → 应该拿石头"
输出动作: <抓石头>
```

论文展示的经典例子：模型选择"石头"作为临时锤子、"能量饮料"给疲惫的人——这些是纯机器人数据教不会的，必须来自互联网常识。

## 六、模型实例与规模

| 模型 | 基座 VLM | 参数 |
|------|---------|------|
| RT-2-PaLI-X (5B) | PaLI-X | 5B |
| RT-2-PaLI-X (55B) | PaLI-X | 55B |
| RT-2-PaLM-E (12B) | PaLM-E | 12B |

大模型版本（55B）显著优于小版本，证明**机器人控制也能从 LLM 规模定律中受益**。

## 七、实验与结果

- **6000 次**真实机器人评测试验。
- 在**已知任务**上保持或超越 RT-1。
- 在**未知物体、未知指令、未知场景**的泛化上大幅领先：
  - 对 unseen 物体/场景的零样本泛化显著提升。
  - 符号/语义推理任务（如"拿到数字 2 的方块"）成功率远高于基线。
- 思维链使得多步语义推理任务成为可能。

## 八、与同类物理 AI 路线对比

| 模型 | 范式 | 动作表示 | 知识来源 | 开放性 |
|------|------|---------|---------|--------|
| RT-1 | 专用策略网络 | 连续回归 | 仅机器人数据 | 闭源 |
| **RT-2 (本文)** | **VLA（动作=token）** | **离散 token** | **网页+机器人联合** | 闭源 |
| OpenVLA | VLA（开源） | 离散 bin | OXE（970k） | **开源** |
| VIMA / Octo | 扩散/Transformer | 连续 | 多数据集 | 开源 |
| GR00T / Cosmos | VLA + 世界模型 | 混合 | 仿真+真实 | 半开源 |

RT-2 开创了 VLA 范式，OpenVLA 把它开源化，GR00T/Cosmos 则进一步引入世界模型做预测式控制——这是物理 AI 的一条清晰主线。

## 九、局限性

1. **闭源**：RT-2 权重未公开，社区难以复现与改进。
2. **动作离散化损失**：连续动作被量化到 256 bin，精细操作（如插拔、拧螺丝）精度受限。
3. **实时性**：55B 模型推理慢，难部署到边缘机器人。
4. **数据仍依赖遥操**：机器人侧数据仍需人工采集，未根本解决"机器人数据稀缺"。
5. **无世界模型**：RT-2 是"反应性"策略，不做未来预测/规划。

## 十、总结

RT-2 的遗产是 **VLA 范式本身**：把动作变成 token，让"互联网知识"与"机器人控制"在同一个模型里统一。它证明了**数据管道的范式（海量网页数据 + 稀缺机器人数据联合）**比单纯堆机器人数据更有效。这一思想直接催生了开源的 OpenVLA、以及今天 NVIDIA GR00T、Cosmos 等物理 AI 体系——我们在《多模态数据处理》中强调的"用 Tag 做概念平衡、用双写存储支撑大规模混合数据"正是服务于这类跨域联合训练。
