# 第 8 章：世界模型训练流程——数据策展、Tokenizer 与渐进训练

## 8.1 世界模型训练全景

世界模型的训练与 VLA 有本质不同——VLA 的训练信号是"模仿专家动作"，世界模型的训练信号是"预测世界如何变化"。

```
世界模型训练全流程:

Stage 1: 视频数据策展 (Curation)
  2000万小时原始视频 → 1亿条高质量片段
  ↓
Stage 2: Tokenizer 训练
  视频帧 → token (连续或离散)
  ↓
Stage 3: 预训练 (Pre-training)
  大规模视频上的世界动力学学习
  ↓
Stage 4: 动作条件化 (Action Conditioning)
  加入动作输入, 使模型可控
  ↓
Stage 5: 后训练 (Post-training)
  针对特定 Physical AI 场景微调
```

## 8.2 Stage 1：视频数据策展

### 8.2.1 Cosmos 的视频策展管线

Cosmos 从 2000 万小时原始视频中提取 1 亿条 2-60 秒的高质量片段，管线包含 7 个步骤：

```
原始视频 (20M 小时)
  │
  ├─ Step 1: 视频分割 (Shot Detection)
  │   将长视频切分为场景级片段
  │
  ├─ Step 2: 质量过滤 (Quality Filtering)
  │   过滤: 分辨率<480p、模糊、压缩伪影严重
  │   工具: 图像质量评估模型
  │
  ├─ Step 3: 动态性过滤 (Motion Filtering)
  │   过滤: 静态画面（低光流）、过度抖动
  │   工具: 光流大小 + 运动幅度统计
  │   目标: 保留"有丰富物理动态"的片段
  │
  ├─ Step 4: 文本标注 (Captioning)
  │   每 256 帧用 VLM 生成一段描述
  │   工具: 大型 VLM (InternVL 级别)
  │
  ├─ Step 5: 去重 (Deduplication)
  │   用 InternVideo 提取视频嵌入
  │   聚类 → 计算簇内距离 → 去除高度相似视频
  │   保留高分辨率版本
  │
  ├─ Step 6: 安全过滤 (Safety Filtering)
  │   Pre-Guard: 过滤有害内容
  │
  └─ Step 7: 切片 (Slicing)
      切分为 2-60 秒的训练片段
      → 产出: ~1 亿条高质量片段
```

### 8.2.2 关键过滤标准

| 过滤维度 | 保留标准 | 丢弃原因 |
|----------|----------|----------|
| 分辨率 | ≥ 480p | 低分辨率无法学习细节物理 |
| 运动量 | 光流均值 > 阈值 | 静态画面无动力学信息 |
| 场景类型 | 多样（室内/室外/道路/自然） | 需覆盖 Physical AI 的各种场景 |
| 视频质量 | 清晰、无严重压缩伪影 | 伪影会误导物理学习 |
| 内容安全 | 无有害/不适内容 | 安全合规 |
| 去重 | 簇内距离 > 阈值 | 重复数据浪费训练资源 |

### 8.2.3 V-JEPA 2 的数据组成

V-JEPA 2 使用 VideoMix22M 数据集（2200 万视频），组成如下：

| 来源 | 规模 | 特点 |
|------|------|------|
| SSv2 | ~170K | 日常动作识别 |
| Kinetics 400/600/700 | ~650K | 人类动作 |
| HowTo100M | ~136M | 教学视频（含语音） |
| ImageNet | ~1.3M | 图像（用于混合训练） |
| YT-Temporal-1B 精选 | ~15M | YouTube 时序视频 |

不同来源的视频通过**手动调优的采样权重**混合，确保训练时各类视频的比例均衡。

### 8.2.4 Ray 编排管线

Cosmos 的视频处理管线使用 Ray 编排，因为不同处理步骤的吞吐量差异巨大：

```
视频解码 (GPU H.264 硬解): 1000+ fps
质量评估 (CNN 推理):        200 fps
光流计算:                    50 fps
VLM 标注:                    5 fps
去重嵌入:                    100 fps
```

Ray 的任务编排让不同吞吐量的步骤并行流水线化，最大化整体吞吐。

## 8.3 Stage 2：Tokenizer 训练

### 8.3.1 Cosmos-Tokenizer

Cosmos 开发了专用视频 Tokenizer，支持连续和离散两种模式：

| 模式 | 压缩率 | 用途 | 代表配置 |
|------|--------|------|----------|
| 连续 | 8×8×8 (T×H×W) | 扩散模型预训练 | CV8x8x8 |
| 离散 | 8×16×16 | 自回归模型预训练 | DV8x16x16 |

**因果时间设计**：Cosmos-Tokenizer 的关键创新是**因果时间卷积**——每帧的 token 化仅依赖当前帧和之前的帧，不被未来帧影响。这保证了自回归训练时的因果性。

```
两级小波变换:
  帧 [1,2,3,4] → 组1 (低频: 帧1+2, 高频: 帧1-2)
  帧 [5,6,7,8] → 组2 (低频: 帧5+6, 高频: 帧5-6)
  ...

每组 4 帧被压缩为 1 个时间 token。
```

### 8.3.2 Tokenizer 性能对比

| Tokenizer | 压缩率 | 重建质量 (PSNR) | 时间因果性 |
|-----------|--------|-----------------|------------|
| Cosmos-CV8x8x8 | 512× | 35.2 dB | ✅ |
| Cosmos-DV8x16x16 | 2048× | 32.1 dB | ✅ |
| CogVideoX-Tokenizer | 512× | 33.8 dB | ❌ |
| FLUX-Tokenizer | 256× | 34.5 dB | ❌ |
| VideoGPT-Tokenizer | 256× | 30.2 dB | ❌ |

Cosmos-Tokenizer 在相同压缩率下重建质量最优，且是唯一支持时间因果性的——这对自回归训练至关重要。

### 8.3.3 V-JEPA 2 的"无 Tokenizer"设计

V-JEPA 2 不使用传统 Tokenizer——它的"Tokenizer"就是 ViT 编码器本身：

```
传统: 视频 → Tokenizer → token → 模型
V-JEPA 2: 视频 → ViT patchify → patch embedding → 编码器 → 潜在表示
```

V-JEPA 2 使用 **Tubelet Patchify**（2×16×16 的管状切片），直接将视频转换为 patch 序列，无需单独训练 Tokenizer。这是 JEPA 范式的优势之一——少一个需要训练的组件。

## 8.4 Stage 3：预训练

### 8.4.1 Cosmos 扩散预训练

Cosmos 扩散模型的两阶段预训练：

**阶段 A: Text2World**

```
输入: 文本提示
输出: 生成视频
训练: 标准文本到视频扩散训练
```

**阶段 B: Video2World**

```
输入: 文本提示 + 当前观测帧
输出: 未来视频
训练: 在 Text2World 基础上, 加入输入视频作为条件
```

Video2World 是 Physical AI 的关键——给定机器人当前看到的画面，预测接下来会发生什么。

### 8.4.2 Cosmos 自回归预训练

自回归模型的多阶段训练：

```
阶段 1: 纯视频预测 (17帧)
  输入: 帧[0:16] → 预测帧[17]
  
阶段 2: 扩展到 34 帧
  输入: 帧[0:33] → 预测帧[34]
  
阶段 3: 加入文本条件
  输入: 帧[0:N] + 文本描述 → 预测帧[N+1]
  
阶段 4: Cooling-down
  用高质量子集微调, 线性衰减学习率
```

### 8.4.3 V-JEPA 2 的预训练

V-JEPA 2 的预训练更加简洁——单一阶段的掩码预测：

```
输入: 视频片段, 部分区域被掩码
编码器: 处理可见区域 → z_context
预测器: z_context + mask信息 → ẑ_predicted
目标: z_target = EMA_encoder(被掩码区域)
损失: L1(ẑ_predicted, z_target)
```

**渐进分辨率策略**：

```
Warmup + Main 阶段:
  16 frames @ 256×256 分辨率
  占训练时间 ~80%
  
Cooldown 阶段:
  64 frames @ 384×384 分辨率
  占训练时间 ~20%
  
效果: 8.4× GPU-time 节省 (vs 全分辨率训练)
```

### 8.4.4 训练超参对比

| 超参 | Cosmos Diffusion 14B | Cosmos AR 13B | V-JEPA 2 (1B) |
|------|----------------------|---------------|----------------|
| 训练数据 | ~1亿片段 | ~1亿片段 | 2200万视频 |
| 分辨率 | 720p | 720p | 256²→384² |
| 帧数 | 121 | 121 | 16→64 |
| 上下文长度 | 56,320 | 56,320 | ~16K |
| 精度 | BF16 混合 | BF16 混合 | BF16 |
| 并行 | FSDP=64, CP=8 | TP + SP | FSDP |
| 训练步数 | ~100K+ | ~100K+ | 252K |

## 8.5 Stage 4：动作条件化

### 8.5.1 为什么需要动作条件化

预训练的世界模型只知道"世界如何自行演化"，不知道"如果机器人执行了某个动作，世界会怎样变化"。动作条件化让世界模型变为**可控的世界模拟器**。

### 8.5.2 V-JEPA 2-AC：动作条件预测器

V-JEPA 2 的动作条件化是在预训练后增加的第二阶段：

```
阶段 1 (预训练): 无动作的自监督学习
  编码器 E_θ + 预测器 P_φ 在互联网视频上预训练
  产出: 理解世界动力学的编码器

阶段 2 (V-JEPA 2-AC): 动作条件化微调
  加入动作信息到预测器: P_φ(z_context, a_t) → ẑ_{t+1}
  数据: 62 小时 Droid 机器人视频 (无标注!)
  目标: ||P_φ(z_context, a_t) - z_target||₁
```

**关键**：62 小时机器人数据是**无标注的**——不需要人工标注"这一步做了什么动作"。V-JEPA 2 从视频帧间变化中推断动作效果。

### 8.5.3 Cosmos 的后训练动作条件化

Cosmos 通过后训练将预训练 WFM 特化为特定 Physical AI 场景：

| 后训练类型 | 条件输入 | 数据 | 应用 |
|------------|----------|------|------|
| 相机控制 | Plücker 线嵌入 (相机位姿) | DL3DV-10K | 场景导航 |
| 机器人操作 | 动作命令 + 指令 | 机器人演示 | VLA 合成数据 |
| 自动驾驶 | 轨迹 + 传感器 | 驾驶视频 | 自动驾驶仿真 |

### 8.5.4 Genie 3 的潜在动作模型

Genie 3 不需要外部动作输入——它自己从视频中学习"潜在动作"：

```
训练:
  帧_t, 帧_{t+1} → Latent Action Model → 潜在动作 a_t (离散编码)
  (帧_t, a_t) → Dynamics Model → 预测 帧_{t+1}

推理:
  用户按键 → 映射到潜在动作 a_t
  (当前帧, a_t) → Dynamics Model → 下一帧
```

这种设计使 Genie 3 能从无标注的互联网视频中学习交互式世界，无需任何动作标注。

## 8.6 Stage 5：后训练（Post-training）

### 8.6.1 后训练的目标

预训练的 WFM 是"世界模型通才"——它理解一般性的物理规律，但可能不精确。后训练使其特化为特定 Physical AI 场景的"专家"。

### 8.6.2 Cosmos 后训练示例

**机器人操作后训练**：

```
预训练: Cosmos-Diffusion-7B-Video2World (通才)
  ↓
后训练数据: 机器人演示 (图像, 动作, 指令) 对
  ↓
条件: 当前帧 + 动作命令 + 语言指令
  ↓
产出: Cosmos-Diffusion-7B-Video2World-Robot-Manip (专家)
```

后训练使用 `O(10K)` 次迭代，线性衰减学习率。Cosmos 论文发现后训练可以显著提高生成视频的质量——不仅特化了场景，还提升了整体保真度。

### 8.6.3 安全护栏

Cosmos 在预训练和后训练中都部署了安全机制：

```
Pre-Guard (输入安全):
  用户提示 → 安全分类器 → 拒绝有害请求

Post-Guard (输出安全):
  生成视频 → 安全分类器 → 过滤有害内容
```

## 8.8 小结

世界模型训练流程的核心要点：

1. **数据策展是天花板**：从 2000 万小时到 1 亿片段，7 步管线决定模型质量上限
2. **Tokenizer 是压缩器**：Cosmos-Tokenizer 的因果时间设计是自回归训练的前提
3. **渐进训练省 8.4×**：先低分辨率预热，再高分辨率冷却
4. **动作条件化是关键转化**：将"世界观察者"变为"可控模拟器"
5. **后训练做特化**：O(10K) 步即可将通才 WFM 变为场景专家
