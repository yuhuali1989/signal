# 第 8 章 · 终章：怎么判断转型成不成

## 8.1 为什么需要一份「判断标准」

AI 转型最大的风险不是做错，而是**无法判断做得对不对**。

行业里充斥着无法证伪的说法：效率提升、体验改善、智能化升级。而金蝶的价值在于它给出了**带数字的目标**（2030 年 AI Native 收入占比 50%），Salesforce 的价值在于它发明了**可计量的单位**（AWU），Adobe 的价值在于**单独披露 AI-first ARR**。

本章把这些做法抽象成一套通用判断框架。

## 8.2 六个可验证信号

判断一家传统软件厂商的 AI 转型是否走在正确轨道上，看这六个信号——**按可信度从高到低排列**：

### 信号一：AI 收入是否单独披露，且在持续放大

| 参考 | 数字 |
|---|---|
| Salesforce | Agentforce + Data 360 **ARR 39 亿美元，+210%** |
| Adobe | AI-first ARR **同比 3 倍，超 5 亿美元** |
| 金蝶 | 2025 年 AI 签约 **3.56 亿元** → 2030 目标 AI Native 占比 **50%** |

**为什么排第一**：这是唯一无法用叙事替代的指标。不敢单独披露，往往意味着数字不好看。

### 信号二：客户侧是否出现「可审计的业务指标」改善

优先相信这类指标（财务口可审计）：

- 凭证自动化率 **95%+**
- 核算自动化率 **98%**
- 每月结账天数**缩短 60%**
- 物料编码数量**减少 60%**、BOM 出错率**降低 15%**

**警惕**"效率提升 N 倍""用户满意度大幅提升"这类无法审计的表述。

### 信号三：存量客户的 AI 转化率

Salesforce 超过 **50%** 的 Agentforce 与 Data 360 订单来自存量客户。

**这个信号揭示了一个反直觉的事实**：AI 收入的主要来源不是新客户，而是**老客户升级**。所以判断厂商能否做成，要看它的存量客户基础里有多少**已经上云、数据标准化程度够好**——这正是 SAP 的痛点（60% 存量未上云）。

### 信号四：定价模式是否真的切换了

看它是否推出了**非席位计价**，且不只是加购包：

- Salesforce $2/次自主解决、AWU 累计 70 亿个（季度环比 +97%）
- SAP 动作池 + 超额 agent run $0.40–1.80
- Workday Flex Credits 1–750 分级
- ServiceNow 按 action 计量

**如果一家公司只有"AI 高级版加价"，说明定价还没真正切换。**

### 信号五：是否建立了「收费站」

看它有没有能力**对外部 Agent 的访问计量并收费**：

- SAP API Policy v4 §2.2.2 明文禁止外部 Agent 绕过其技术栈调用 API
- ServiceNow Action Fabric 按 action 收费
- Workday 对约 30 家企业收紧 API 治理

**这个信号决定了长期定价权**——谁掌握 Agent 访问的必经通道，谁就能把"席位流失"转成"调用收入"。

### 信号六：人才结构是否在替换而非单纯缩减

看裁员的同时 AI 岗位是否在扩招（Oracle 裁 3 万、Salesforce 裁 4000 的同时，Agentforce ARR 增长 210%）。

## 8.3 六个常见陷阱

### 陷阱一：把 AI 当销售标签

《中国企业家》的观察：去年 CEO 们谈的还是"如何把 AI 转化为辅助销售的标签"。**只改话术不改产品，试用一轮就会露馅，且加速信任流失。**

### 陷阱二：做一个聊天框就算 AI 化

判断标准：**AI 能否改变系统里的一个状态**（生成凭证、发起审批、更新记录）？不能，就还是玩具。

### 陷阱三：让 Agent 绕过既有治理

为体验流畅而绕开审批链、权限校验、审计记录——短期好用，长期必出事。**企业软件里治理是产品的一部分。**

### 陷阱四：在模型层竞争

试图自研比通用模型更强的模型。**你的优势从来不在模型，而在上下文与治理继承**（第 4 章）。SAP 只做"最复杂企业问题"的 Agent，就是承认这一点。

### 陷阱五：跳过云迁移直接上 Agent

SAP 60% 存量未上云是它的结构性阻力。中国厂商的本地部署与老版本占比只会更高。**Agent 路线的前提是数据与流程在可控的新架构上**，这一步无法跳过。

### 陷阱六：用「AI 收入增长」掩盖「存量业务失血」

必须同时看两个数：AI 收入增速 **和** 传统许可收入的绝对值变化。Salesforce 的 AI ARR 增长 210% 之所以有意义，是因为它**抵消了传统许可收入的波动**——如果只看前者，会误判。

## 8.4 转型 Checklist（十二项）

给决策者的可勾选清单：

**战略层**
- [ ] 有带数字、带年份的 AI 目标（而非形容词）
- [ ] 明确了「Agent 替代 ERP」还是「AI 原生 ERP」的路线选择
- [ ] 存量客户的上云/迁移进度已量化，并有明确时间表

**产品层**
- [ ] Agent 与业务系统**共用一套**主数据、权限、业务规则
- [ ] Agent 能**调用原生交易与流程**，而非模拟 UI
- [ ] 有可搭建能力（no-code/low-code），业务人员能参与
- [ ] 支持 MCP / A2A 等 Agent 互操作协议

**商业层**
- [ ] 已推出非席位计价（用量/动作/结果至少一种）
- [ ] 有 AI 收入的单独披露口径
- [ ] 建立了外部 Agent 访问的计量与管控（收费站）

**组织层**
- [ ] 有 FDE 或等价的现场工程角色
- [ ] 定制化交付能力正在被沉淀为 Skill / 平台能力

## 8.5 全书二十条结论

**处境（第 1 章）**
1. 标普软件指数自 2025-10 高点累计跌超 33%，Claude Cowork 上线令板块六连跌、蒸发约 8300 亿美元——这不是周期，是结构性质疑。
2. 席位制的经济基础已被打破：纯席位定价厂商占比 12 个月内从 21% 降至 15%。
3. 被商品化的是**功能与界面层**；被强化的是**系统连接、权限、合规、历史数据、固化流程**。
4. Gartner 定性为**蜕变而非末日**（metamorphosis）；到 2030 年 2340 亿美元企业应用软件支出将受影响。
5. 中国市场额外承压：2025 年企业级 SaaS 增速 22.3%（低于 2024 的 29.7%），用友亏 9.45 亿、金蝶亏 0.98 亿。

**样本（第 2 章）**
6. 金蝶把主品牌从"金蝶云"改为"金蝶 AI"，等于把公司信用押在转型上——**看预算流向比看演讲可靠**。
7. 目标是可验证的：2030 年 AI Native 收入占比 50%；2025 年 AI 签约仅 3.56 亿，基数仍小。
8. 灵基的关键架构决策：Agent 与业务系统**共用组织、主数据、业务规则、权限**，可直调原生交易与流程。

**路线（第 4 章）**
9. 四家巨头不约而同选「AI 原生」而非「Agent 替代 ERP」——因为它们知道系统级工程绕不过去。
10. Agent 的能力上限不取决于模型，而取决于**能触达多少带上下文的业务数据**与**在什么治理下执行**。
11. 实务上按风险分层：信息型可放手，**交易型与决策型必须守在系统内**。
12. 路线 B 的代价：云迁移包袱（SAP 60% 未上云）、体验上限受限、双栈维护成本。

**产品（第 5 章）**
13. 定位跃迁的本质：从"记录发生过什么"到"告诉你该做什么"，且**责任边界必须重新划清**。
14. 「AI 财务部」（15 个智能体三层）的形态值得参考：**人在关键环节决策**。
15. 企业 AI 独有硬约束是**可审计性**——这也是老牌厂商相对 AI 原生创业公司的优势区。

**商业（第 6 章）**
16. 六种计价货币并存且无标准：Salesforce $2/次、HubSpot $0.5、Intercom 不成功不收费、Microsoft $0.01/credit、SAP 超额 $0.40–1.80、Workday 1–750 credits。
17. **收费站是最有力的反击**：一个 Agent 月产 5 万次 API 调用，把"席位流失"转成"调用收入"。
18. AI 收入主要来自**存量客户升级**（Salesforce 50%+），不是新客户。

**组织（第 7 章）**
19. FDE 模式是 AI 交付的必然；中国厂商的定制化包袱可转化为优势，路径是**把定制化产品化成 Skill**。
20. AI 转型期要区分**防御性裁员**与**结构性替换**——看 AI 岗位是否同步扩招。

## 8.6 最后一句话

回到全书开头的问题：金蝶这样的传统软件厂商，出路在哪？

答案不在"做更强的 AI"，而在三件事：

> **把 Agent 长在自己最懂的业务上**（而不是去和通用模型比聪明）；
> **把价值从界面层搬到系统层与结果层**（而不是守着按人头收费）；
> **把开放的边界划清楚**（底座与协议开放换生态，事务与治理守住换收费站）。

徐少春说"暴风雨只会让强者更强"，SAP 的柯睿安说"我们的 ERP 承载世界上最复杂的业务流程"。这两句话放在一起，就是这场转型最诚实的注脚：

**AI 不会杀死软件公司，但它会杀死"只卖界面和席位"的软件公司。**
